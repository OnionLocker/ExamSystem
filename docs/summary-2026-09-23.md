## ✅ 已实现（可立即使用）

### 1. 知识债看板（A1）

**位置：** 知识点页 → 知识债页签

**功能：**
- 显示 87 笔未清债务，按 `错次 × 天数` 紧急度排序
- 每笔债显示：考点、累计错次、连对进度（0/2→1/2）、最近错误日期、掌握度
- 顶部汇总：未清 N 笔 / 本周清掉 M 笔
- **一键出变式卷**：每行都有按钮，点击自动生成 5 题该考点练习并跳转

**价值：** 87 笔债从「只在后端」→「可见可操作」，立刻可清偿

### 2. Hermes 策略增强（A4）

**实现：** `scripts/learner_snapshot.py` 输出增强

**效果：**
```
知识债（连对2次才算清偿；连对为0且错次高的，优先安排同考法变式卷，不要开新考点）：
  - 数量关系-数学运算-工程问题｜累计错32次｜连对0/2 距上次错5天
  - 数量关系-数学运算-行程问题｜累计错28次｜连对0/2 距上次错3天
  ...
```

**价值：** Hermes 现在能看到债务数据，给出「先清这几笔债」的精准建议，不再只说「低置信待测」

**规范内容：**

## 🚀 立即可用的操作流程

### 用户视角

1. **查看知识债**
   ```
   打开「知识点」页
   → 点击「知识债」页签
   → 看到 87 笔债务列表（按紧急度排序）
   ```

2. **清偿一笔债**
   ```
   找到最紧急的债务
   → 点击「出这个考点的变式卷」
   → 自动跳转到 5 题练习
   → 做完交卷 → 连对进度 +1
   → 连对 2 次该债自动清偿
   ```

3. **让 Hermes 排计划**
   ```
   问「现在该练什么」
   → Hermes 调用快照看到债务
   → 回答「先清这几笔债：XXX、YYY」
   → 给出具体考点和理由
   ```

### 开发者视角

```bash
# API 测试
curl http://localhost:5173/api/kaodian/debts
# 返回债务列表 + 汇总

curl -X POST http://localhost:5173/api/quiz/lite \
  -H "Content-Type: application/json" \
  -d '{"module":"数量关系","tag":"数量关系-数学运算-工程问题","count":5}'
# 返回 sessionId，前端跳转练题

# 快照测试
python3 scripts/learner_snapshot.py --compact
# 输出包含「知识债」段落
```
