## 技术细节

### merge_answers.py 工作原理
- 从答案 PDF 提取 "正确答案：X" 文本块
- 按 (页码, y坐标) 排序，保证题号顺序
- 通过题数对齐校验（答案数 = 题数）
- 自动跳过 orphan（number 为 null 的碎片）
- 处理重复上传（如 `(1)` 后缀），取答案更多的版本

### 为什么不能从原题 PDF 提取答案
- 原题 PDF 只有题干和选项，不含正确答案
- 需要独立的答案 PDF（通常是配套资料）
