# 🚀 快速启动指南

## 立即可用的功能

### 1️⃣ 查看知识债（87笔待清）

```bash
# 1. 确保服务运行
npm run dev

# 2. 打开浏览器
http://localhost:5173

# 3. 登录后进入「知识点」页面

# 4. 点击「知识债」页签

# 5. 看到按紧急度排序的87笔债务
```

**你会看到：**
- 考点名称（如：数量关系-数学运算-排列组合问题-位置限制）
- 累计错误次数（如：32次）
- 连对进度（如：0/2）
- 最近错误日期（如：5天前）
- 当前掌握度（如：35%）

### 2️⃣ Hermes智能出题清债

**操作步骤：**
1. 在债务列表中，点击任意债务的「让 Hermes 出这个考点的题」按钮
2. 自动跳转到 Hermes 页面
3. Hermes 接收到结构化指令：
   ```
   #出题清债#
   考点: [具体考点]
   模块: [所属模块]
   累计错误: [N]次
   连对进度: [0/2]
   掌握度: [X]%
   
   请针对该考点出5道题，难度分布：easy 2题, mid 2题, hard 1题。
   题目要覆盖该考点的不同变式，不要重复同一场景只换数字。
   ```
4. Hermes 开始出题，你可以：
   - 追问要求调整难度
   - 要求补充解析
   - 边做边问疑问

### 3️⃣ 交卷后复盘提醒

**场景：** 做完题交卷后

**你会看到：**
- 成绩卡片（对了X/总数道）
- 🟠 橙色警告卡片：「这场还有 N 道题的证据没写」
- 详细说明：为什么要复盘
- 一键按钮：「让 Hermes 复盘这场」

**为什么重要：**
- 不复盘 = 画像只记空题（坏消息）
- 复盘 = 对的题、错的题都记录（完整画像）

### 4️⃣ 债务清偿流程

**目标：** 连对2次，清偿债务

**流程：**
```
第1次 → Hermes出题 → 做题 → 对了4/5 → recovery_streak = 0（有错，归零）
第2次 → Hermes出题 → 做题 → 全对！ → recovery_streak = 1
第3次 → Hermes出题 → 做题 → 全对！ → recovery_streak = 2 → 🎉 债务清偿！
```

**债务清偿后：**
- 从债务列表消失
- 掌握度提升
- 汇总显示「本周清掉 M 笔」

## 🛠️ 配置调整（可选）

### Hermes 工具护栏

编辑 `~/.hermes/config.yaml`：

```yaml
tool_loop_guardrails:
  hard_stop_enabled: true          # 防止工具死循环
  hard_stop_after:
    exact_failure: 3
    same_tool_failure: 4
    idempotent_no_progress: 3
agent:
  max_turns: 30                    # 防止单轮过长
```

### 钩子脚本（防止误改代码）

创建 `~/.hermes/agent-hooks/pre-write.sh`：

```bash
#!/bin/bash
FILE="$1"

# 允许写入：复盘报告、笔记、技能文档
if [[ "$FILE" =~ ^data/(practice-reviews|exam-reviews|voice-notes) ]] || \
   [[ "$FILE" =~ ^hermes-skills/ ]]; then
  exit 0
fi

# 禁止直接写入：代码和配置
if [[ "$FILE" =~ ^(src|server|scripts)/ ]]; then
  echo "❌ 禁止写入 $FILE，需先说明并确认"
  exit 1
fi

exit 0
```

安装：
```bash
chmod +x ~/.hermes/agent-hooks/pre-write.sh
```

## 🆘 常见问题

### Q1: 知识债页面是空的？
**A:** 检查是否已登录，确认数据库路径正确（`data/exam.db`）

### Q2: 点击出题按钮没反应？
**A:** 检查浏览器控制台错误，确认 Hermes 服务运行正常

### Q3: 复盘后债务还在？
**A:** 需要连对2次才清偿，单次对了不够

### Q4: 背景色看起来还是太白？
**A:** 在 `src/knowledge/Knowledge.jsx` 中可以调整色值：
```jsx
// 当前
bg-[#fdfbf7]  // 米白

// 改为更暖
bg-[#f9f3e8]  // 明显的奶黄
```

### Q5: Hermes出的题不够好？
**A:** 可以在Hermes中追问：
- "这道题太简单了，能出个难的吗"
- "能换个考法吗"
- "能详细讲讲这道题的解法吗"
