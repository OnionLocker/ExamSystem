# 问题修复方案

## 问题1：知识债数据不显示（显示"未清0笔"）

### 根本原因
API `/api/kaodian/debts` 需要身份验证，但前端调用时可能没有正确传递cookie。

### 解决方案

在 `DebtDashboard.jsx` 中修改API调用，添加credentials：

```javascript
async function loadDebts() {
  try {
    const res = await fetch('/api/kaodian/debts', {
      credentials: 'include'  // 添加这一行，确保cookie被发送
    });
    if (!res.ok) {
      throw new Error(`HTTP ${res.status}`);
    }
    const data = await res.json();
    setDebts(data.debts || []);
    setSummary(data.summary || { open: 0, clearedThisWeek: 0 });
  } catch (error) {
    console.error('Failed to load debts:', error);
    setDebts([]);
    setSummary({ open: 0, clearedThisWeek: 0 });
  } finally {
    setLoading(false);
  }
}
```

## 问题2：按钮颜色看起来是白色

### 根本原因
当前使用的 `bg-[#faf6ec]` 是很浅的奶黄色，在某些显示器上看起来接近白色。

### 解决方案

将所有未选中的按钮颜色改为更明显的暖色：

```javascript
// 在 Knowledge.jsx 中修改按钮样式
className={`min-h-[40px] px-4 py-2 rounded-full text-sm font-bold ${
  view === 'tree' 
    ? 'bg-[#1a1a1a] text-white' 
    : 'bg-[#e8d5b0] border border-[#c4ae7a] text-[#6b5428]'  // 改为更明显的暖褐色
}`}
```
