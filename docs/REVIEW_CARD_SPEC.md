# 复习卡片 · 统一视觉规范 & Prompt 模板

> **给 agent 的说明**：本文件是「公考知识卡片」小红书系列的唯一视觉基准。
> 需要新出一期时：读本文件 -> 套用第 3 节模板 -> 填入本期内容 -> 交给图像模型。
> 不要自行发明配色或布局。**系列一致性优先于单张好看**——读者是靠视觉识别账号的。
> 出好的图归档进复习模块（`data/review-images`），prompt 追加到第 4 节。

---

## 0. 风格基准

基准是那张**深红底「资料分析常用公式」速记表**，不是早期的浅色清新卡片。
两者的根本差别不在配色，而在**骨架**：

| | 早期浅色版（已废弃） | 现行红色版 |
|---|---|---|
| 排版 | 单列居中，行间大留白 | 三列表格，行间细线分隔 |
| 气质 | 清新、松 | 教辅速记表、紧 |
| 强调色 | 每个板块换一套字色 | 字色统一主红，只换板块条底色 |

**手边有基准图时，务必作为参考图（style reference）一并传给图像模型。**
纯文字 prompt 能还原配色，还原不了三列骨架——这是实测结论。

## 1. 视觉规范（不可改动）

### 画布
- 比例 **9:16**，建议 1080×1920
- 外圈一道**深正红实色边框 `#C1121F`**，约 24px，**直角**

### 配色表

| 用途 | 色值 |
|---|---|
| 主红：边框 / 标题条 / 底部条 / 编号圈 / 强调字 | `#C1121F` |
| 纸底（微暖米白） | `#FDFAF3` |
| 公式框底（米黄） | `#FDF6E3` |
| 行间分隔线（淡红灰） | `#EADCDC` |
| 注解灰字 | `#8C8C8C` |
| 板块条底 · 粉 | `#FCE8E6` |
| 板块条底 · 橙 | `#FEF7E0` |
| 板块条底 · 蓝 | `#E8F0FE` |
| 板块条底 · 绿 | `#E6F4EA` |

板块条底色按期自由切换，**但字色永远是主红 `#C1121F`，不要跟着底色变**。
这条是系列感的主要来源，也是和废弃浅色版最大的区别。

### 字体
- 中文：特粗黑体（思源黑体 Bold 质感）
- 逻辑式 / 公式：**衬线数学体（LaTeX Computer Modern 质感）**，务必与中文形成对比
- 注解：常规黑体小字

### 禁止项
直角不圆角外框 · 不要渐变 · 不要阴影 · 不要 emoji · 不要插画人物照片 ·
不要英文水印 / logo / 页码 · 不要大片留白

## 2. 布局骨架（五段式，每期都一样）

1. **顶部标题条**：通栏主红实底，白色特粗大字居中，内侧勾一道细白线。
   标题控制在 **10 字内**；期号放在标题条右端，白色小字「DAY 0X」。
2. **总纲行**（不带编号）：左=「核心读法」类标签，中=本期最核心的那一个式子，
   右=两行灰字点题。相当于全卡的题眼。
3. **板块**（1¬3 个）：每个板块一条通栏浅色小标题条，左端立一道主红竖条，主红粗字。
4. **板块内的行**，统一三列：

   | 左 30% | 中 40% | 右 30% |
   |---|---|---|
   | 主红粗体中文，前置主红实心圆圈白数字 | 米黄圆角框（`#FDF6E3` + 1px 主红细边）内黑色数学体式子，居中 | 灰色注解，最多两行 |

   行与行之间一道细淡红横线 `#EADCDC`。
5. **底部口诀条**：通栏主红实底，白色粗体 2¬3 行居中，字号逐行递减。

### 密度要求
正文 **8¬15 行**为佳。内容不够时**不要拉大行距**，用「等价形式」「反例」
「易错提醒」「递推规则」补成独立行。空版面会立刻失去速记表的质感。

## 4. 已出实例

### DAY 01 · 翻译推理核心法则

```text
一张小红书竖版知识卡片，比例 9:16（1080×1920），中文教辅「考试速记表」印刷风格，信息密度高，排版严整不留大片空白。

【整体框架】
外圈包一道厚重的深正红实色边框（#C1121F，约 24px），边框内是微暖的米白纸底（#FDFAF3）。所有中文用特粗黑体（思源黑体 Bold 质感），所有逻辑式用衬线数学体（LaTeX Computer Modern 质感）。直角，不要圆角外框，不要渐变，不要阴影。

【顶部标题条】
通栏深正红实底（#C1121F），内侧勾一道细白线。白色特粗黑体大字居中：「翻译推理核心法则」。标题条右端一行白色小字：「DAY 01」。

【总纲行】（紧接标题条下方，不带编号）
左侧深红粗字「核心读法」；中间一个浅米黄圆角方框（底 #FDF6E3，1px #C1121F 细边框），框内黑色大号数学体：A → B；右侧灰字（#8C8C8C）小字两行：「箭头前是充分条件，箭头后是必要条件」「肯前必肯后，否后必否前」。

【主体：两个板块，共 15 行，统一三列结构】
每行三列：左列约 30%，深红（#C1121F）粗体中文句式，前面带一个深红实心圆圈内嵌白色数字；中列约 40%，浅米黄圆角方框（#FDF6E3 + 1px #C1121F 边框）内居中放黑色大号衬线数学体逻辑式；右列约 30%，灰色（#8C8C8C）小字注解，最多两行。行与行之间用一道细淡红横线（#EADCDC）分隔。

板块一小标题条：通栏浅粉底（#FCE8E6），左端立一道深红竖条，深红粗字「前推后 ▸ 充分条件」。
① 如果 A，那么 B | A → B | 最标准的充分条件句式
② 只要 A，就 B | A → B | 「只要」提示充分，勿与「只有」混
③ 所有 A 都 B | A → B | 全称判断，A 包含于 B
④ 凡是 A 都 B | A → B | 同「所有」，古文式表达
⑤ 若 A，则 B | A → B | 文言句式，等价「如果…那么…」
⑥ A 就 B | A → B | 省略「如果」，靠语序判断
⑦ 为了 A，必须 B | A → B | B 是达成 A 的必要条件
⑧ A 离不开 B | A → B | 「离不开」= 缺 B 则无 A

板块二小标题条：通栏浅橙底（#FEF7E0），左端立一道深红竖条，深红粗字「后推前 ▸ 必要条件」。
① 只有 A，才 B | B → A | 「只有」提示必要，最高频考点
② A 是 B 的前提 | B → A | 前提 = 必要条件
③ A 是 B 的基础 | B → A | 同「前提」一类
④ A 是 B 的必要条件 | B → A | 字面直给，不必转换
⑤ A 是 B 的关键 | B → A | 「关键 / 核心 / 根本」同类
⑥ 不 A 就不 B | B → A | ¬A → ¬B，取逆否即得
⑦ A 是 B 的必经之路 | B → A | 「必由之路 / 唯一途径」同类

【底部口诀条】
通栏深正红实底（#C1121F），白色粗体三行居中，逐行字号递减：
「充分条件前推后，必要条件后推前」
「逆否等价：A → B ⇔ ¬B → ¬A」
「否前、肯后 → 推不出任何结论」

【硬性要求】
严格按上面给定的文案逐字渲染，不得改写、增删、翻译或补充任何文字。不要出现英文说明、水印、logo、页码、装饰插画、人物或照片。所有汉字笔画清晰完整，不得出现错字或乱码。
```

```text

① 除非 A，否则 B | ¬A → B | 「除非」后面取非当前件
② 上式的等价形式 | ¬B → A | 逆否变形，选项常这样出
③ 除非 A，否则不 B | ¬A → ¬B | 后半句自带否定，一并取非
④ 上式的等价形式 | B → A | 逆否后就是「只有 A 才 B」

板块二小标题条：通栏浅蓝底（#E8F0FE），左端立一道深红竖条，深红粗字「四种命题 ▸ 只有一种等价」。
① 原命题 | A → B | 一切变形的基准
② 逆否命题 | ¬B → ¬A | 深红「√」+ 与原命题永远同真同假
③ 逆命题 | B → A | 深红「×」+ 不等价，即「肯定后件」陷阱
④ 否命题 | ¬A → ¬B | 深红「×」+ 不等价，即「否定前件」陷阱
```

## 5. 交付与验收

1. **一定带参考图**。只发文字 prompt，三列骨架大概率被模型改成单列。
2. **逐字渲染**这条要留在 prompt 里，否则模型会自己"优化"文案。
3. **出图必检**三处：错字 / 公式框是否对齐 / `¬`（非号）有没有被漏掉。
   高密度中文是这条路上最大的风险，多抽几张挑一张是常态。
4. 定稿后图片归档进复习模块（`data/review-images`），prompt 追加到第 4 节，
   期号连续，别跳号。

### 关于准确率
基准图那种精度（公式对齐、数学体、行线均匀）更像 HTML + CSS 渲染出来的，
不是图像模型的产物。如果这个系列要长期连载，用代码渲染更省事：文字零错字、
每期间距配色完全一致、改内容只改一行数据。本项目已经有 KaTeX 依赖，
需要时可以做成模板。
