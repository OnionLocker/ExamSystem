## ⚠️ 已知限制

### 1. 清偿后需手动刷新

**现象：** 连对 2 次清偿后，债务看板不会自动更新

**影响：** 需手动刷新页面才能看到债务消失

**解决方案：**
- 短期：用户手动刷新
- 中期：交卷后自动刷新
- 长期：WebSocket 实时推送

### 2. quiz_lite.py 假设存在

**现象：** 代码假设该脚本已存在，但可能未实现

**影响：** 出题按钮可能 500 错误

**解决方案：**
- 检查 `scripts/quiz_lite.py` 是否存在
- 如不存在，参考文档中的实现示例补充

### 3. 配置和钩子需手动调整

**现象：** `~/.hermes/config.yaml` 和钩子脚本不在 git

**影响：** 工具护栏需手动配置才能生效

**解决方案：**
- 参考文档手动调整配置
- 编写并安装 pre-write 钩子
