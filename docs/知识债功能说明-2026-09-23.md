## 🔧 知识债如何运作

### 1. 债务产生机制
```python
# scripts/kaodian_profile.py
DEBT_CLEAR = 2  # 需要连对2次才能清偿

def apply_debt(conn, kaodian, is_correct):
    """
    - 做错一次 → 记一笔债（wrong_count +1，recovery_streak = 0）
    - 做对一次 → recovery_streak +1
    - 连对2次 → 债务清偿（mastered = 1）
    - 中途又错 → recovery_streak 归零重来
    """
```

### 2. 查看知识债
- 打开「知识点」页面
- 点击顶部「知识债」页签
- 看到87笔债务按紧急度排序（错次 × 天数）

### 3. 清偿流程
1. **点击「让 Hermes 出这个考点的题」**
   - 自动跳转到 Hermes
   - 发送结构化指令（包含考点、错误次数、掌握度）
   - Hermes 根据要求出5题（easy 2、mid 2、hard 1）

2. **做题并交卷**
   - 在 Hermes 生成的题目中练习
   - 做对题目，recovery_streak +1

3. **复盘封存**
   - 交卷后点击「让 Hermes 复盘这场」
   - Hermes 分析并写入证据到 kaodian_events
   - 画像更新

4. **债务清偿**
   - 连续做对2次同一考点
   - 债务自动标记为 mastered = 1
   - 从债务列表消失

## 🎨 知识点页面背景色说明

**实际情况：** 知识点页面的背景色**已经是暖色系**，并非纯白色。

### 使用的暖色背景
```css
#fdfbf7  /* 米白色 - 卡片背景 */
#faf6ec  /* 奶黄色 - 区块背景 */
#fdfbf6  /* 暖白色 - 知识点背景 */
#fdf5f2  /* 淡粉白 - 禁区背景 */
#f6ecd4  /* 浅黄褐 - 要点背景 */
#e8d5b0  /* 主色调 - 边框和整体背景 */
```

**可能的误解来源：**
- 在某些显示器上，`#fdfbf7` (米白) 可能看起来接近白色
- 但它确实比纯白色 `#ffffff` 温暖很多
- 这是设计上的选择：保持可读性同时营造温暖感

### 如果需要更暖的背景

可以调整这些颜色值，让暖色调更明显：

```css
/* 当前 → 更暖的版本 */
#fdfbf7 → #f9f3e8  /* 更明显的奶黄 */
#faf6ec → #f5eed8  /* 更明显的米黄 */
#fdfbf6 → #f8f0e3  /* 更暖的米白 */
```

## 🎯 系统设计理念

### 为什么要连对2次？
- 1次可能是运气
- 2次说明真掌握了
- 中途错了就重来，确保扎实

### 为什么不自动出题而是跳转Hermes？
- **更灵活**：可以追问、调整难度、要求解析
- **更可控**：用户能看到出题过程和质量
- **更智能**：Hermes能根据你的理解程度动态调整
- **有记录**：Hermes对话保存了完整学习过程

### 为什么强调复盘？
- 做对的题也要记录（证明掌握）
- 做错的题分析原因（定位问题）
- 空题按停留时长记录（识别盲区）
- **不复盘 = 画像只记坏消息，不记好消息**
