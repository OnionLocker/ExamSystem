# 出题流水线：动态考点与统一审核

Hermes 只认意图。出题、闸门、入库全部由脚本完成。

## 铁律

1. **不要自己写题。** 不要 `write_file` `questions.json`，不要 `search_files` / `ls` / 查库找生成器。
2. **脚本不存在或失败，就报失败。** 禁止回退到自己出题，禁止手跑闸门。
3. **对话里不要打印题干、选项、答案。** 成功只报批次名和题量。
4. **前台 terminal 只有 180 秒。** 出题要几分钟，必须后台跑。
5. **录音请直接听，不要先转写再当用户正文。** 录音说根据快照选定考点并出 N 道，就出那个考点、那个题量。失败报原文，不要翻仓库。

## 批次命名与推进节奏（用户长期要求）

- 题组名必须写全考点、难度和日期：`广东省考行测-{模块}-{考点}-{难度 easy/mid/hard/ladder}-{YYYYMMDD}`。禁止笼统的「专项」。文字专项显式给唯一批次号，重复会被拒；资料入口可自动分配唯一编号。
- **单考法闭环打穿**：一个大考点下的细分考法要连续集中练透再推下一个。同构变式卷 100% 锁在同一考法内，变情境与陷阱，不变底层解题动作，严禁跨考法发散。
- 训练量与难度按当前失分动作和 `exam-sprint-plan.md` 调整。默认少量 mid 验证，不自动为每个子考法连出 mid/hard 两套；hard 仅在需要检验迁移、且基础速度准确率达标时使用。
- 支持数量文字题、言语专项、判断中的纯文字逻辑题、资料文字题与确定性图表题。言语已有题型匹配和重复套路检查，可以按需求生成。
- 政治理论（判断/单选/多选）、常识应用（系统模块名“常识判断”，单选）已接入原文核验出题；具体操作见下文。用户点名模块或知识点就按需生成，不要求先完成固定课程。
- 图形推理、空间推理、科学推理暂不作为可靠 AI 出题能力；使用外采真题。实验图题只能由用户明确发起实验，不能自动入库或混入训练。

## 三步

### 1. 抽出参数

- 模块：判断推理 / 数量关系 / 言语理解与表达 / 资料分析（文字专项）
- 考点 `--tag`：用户或录音点名则写成粉笔 `模块-一级-二级`
  - 平均数问题 → `数量关系-数学运算-平均数问题`
  - 工程问题 → `数量关系-数学运算-工程问题`
  - 排列组合 → `数量关系-数学运算-排列组合问题`
  - 翻译推理 → `判断推理-逻辑判断-翻译推理`
  - 片段阅读 → `言语理解与表达-片段阅读-中心理解题`
- 要更细的考法，先 `--register` 成 L4 再 `--tag`，例如 `数量关系-数学运算-最值问题-最不利原则与抽屉`
- 题量：用户说几道就几道；点名考点没说数量则 **5**；不要擅自出 10 题或成套 20 题

粉笔 L3 是浏览与默认出题单位。旧的超长标签只做 alias，不再往上面出新题。

| 考法 | 识别信号 | 主标签 |
|---|---|---|
| 最值 | 和定排大小、抽屉、反向构造 | `数量关系-数学运算-最值问题` |
| 函数最值 | 二次函数、均值定理、乘积极值 | `数量关系-数学运算-函数最值问题` |
| 排列组合 | 加乘原理、捆绑插空、隔板分堆、错位圆桌 | `数量关系-数学运算-排列组合问题` |
| 概率 | 古典概型、伯努利、赛制决胜 | `数量关系-数学运算-概率问题` |
- **针对性出题与同构变式铁律**：出同构变式卷时，严禁考法发散！变的是业务情境与数值陷阱，不变的是底层解题动作。严禁在同构变式卷中掺入无关或偏门考法（如定位法卷子严禁出成赛制或独立关卡）。
- **套卷与批次三级规范命名**：套卷 source/显示名称统一采用：`广东省考行测-{模块}-{二级题型}-{具体考法/子题型}-{YYYYMMDD}`，禁止笼统写“-专项-”或仅带二级名，确保考生在列表中一眼看出在练哪个考点的具体考法。
- `batch_id`：`YYYYMMDD_hermes_<考点或模块>_<两位序号>`，不得复用已有批次

资料分析共享材料或图表题使用下文专用入口。每日自动成套生成目前全部暂停；按用户当前目标按需出题，不恢复日练调度。

### 2. 考点和要求确认后，后台调用

用户还在讨论知识点拆分时先讨论，不抢先出题。仅改网页讲解不代表新考点已登记；真正要独立出题/评估的子考点须先登记定义，再查询覆盖，确认后调用生成器。

```
terminal({
  command: "python3 /home/ubuntu/ExamSystem/scripts/quiz_lite.py --module '数量关系' --tag '数量关系-数学运算-排列组合问题' --count 5 --batch-id 'YYYYMMDD_hermes_排列组合_01'",
  workdir: "/home/ubuntu/ExamSystem",
  background: true,
  notify_on_complete: true
})
```

等 JSON。成功：`status=success`。失败：把 `message` 原样告诉用户。

### 2a. 脚本内部会怎么审（知道就行，不用你插手）

出稿之后并行跑两个独立审核，都用 Gemini Flash：

- **盲解官**：拿不到答案和解析，自己把题做一遍，报出它算出的选项，并逐个检查还有没有
  第二个选项也站得住。它的答案和题面键定答案不一致，或者发现第二个可成立选项，这题就退回。
  这条是「答案对不对、唯不唯一」的主判官——**不是**拿硬编码算式去套选项。
- **考官**：看得到答案和解析，检查难度、考法、真题风格、解析可复算性，以及用户额外命题要求。跨题配额按整批检查。
- 盲解必须明确返回独立步骤、是否无解、其他可成立选项；字段缺失不得当作通过。两种审核是不同角色的独立调用，不是不同模型的能力认证。

**只有不合格的那几道会被退回重出，已通过的题原样保留**，最多 `--rounds` 轮（默认 3）。
有 `brief` 时，补题后连同保留题一起重审整批要求；若新组合使保留题不再符合要求，也会退回。
所以返回的 `rounds` 里出现多轮、`rejected` 里有题号，都是正常工作，不是故障。
全部通过后脚本自己签精简闸门收据并入库，你不要手跑 `generation_gate` 或 `import-batch`。

### 2b. 要多个考法混在一批，就用 `--blueprint`

用户说「三种题型都要有」「难易结合」「3+3+4」这类**结构化要求**时，
不要退化成单标签，也不要连跑三次。改传蓝图（与 `--tag/--count` 互斥）：

```
terminal({
  command: "python3 /home/ubuntu/ExamSystem/scripts/quiz_lite.py --module '数量关系' --batch-id '20260914_hermes_最值三考法_01' --blueprint '{\"slots\":[{\"tag\":\"数量关系-数学运算-最值问题-最不利原则与抽屉\",\"count\":3,\"difficulty\":\"mid\"},{\"tag\":\"数量关系-数学运算-最值问题-反向构造与多集合最值\",\"count\":3,\"difficulty\":\"hard\"},{\"tag\":\"数量关系-数学运算-最值问题-和定最值与构造\",\"count\":4,\"difficulty\":\"hard\"}]}'",
  workdir: "/home/ubuntu/ExamSystem",
  background: true,
  notify_on_complete: true
})
```

- `slots` 按顺序对应题号；每槽 `tag` 必填、`count` 必填、`difficulty` 选填（`easy`/`mid`/`hard`）。
- 题量总和仍限 1–15；所有槽必须同一模块；标签校验一视同仁，蓝图不放宽。
- 槽位是 Hermes 的编排自由度：**选哪些考法、各几题、难度怎么排由你定；题面仍然由脚本生成，禁止自己写。**
- 太长可写文件再传 `--blueprint @/tmp/bp.json`。

**槽位还能带 `brief`，这是你对本批次的命题指令（自由文本，≤600 字）。**
脚本把登记定义与 `solver-canon` 的「固定识别 / 考场步骤 / 禁止」合并成批次快照，出题和审核共用，
`brief` 是在这个底座之上加你自己的要求——考情、侧重、要避开的退化写法：

```json
{"tag":"数量关系-数学运算-最值问题-最不利原则与抽屉","count":5,"difficulty":"hard",
 "brief":"必须出现残缺抽屉（某类数量不足 n-1）；至少 2 道用复合保证条件；禁止退化成和定排大小。"}
```

- `brief` **只能收紧，不能放宽**。想用它绕开闸门、豁免验算、放行低质量题，一律不行。
- 该写什么：本次侧重的子情形、要避开的退化写法、你联网了解到的新考情、用户临场提的难度要求。
- 不该写什么：题干原文、答案、具体数字——那是脚本的活。

### 2b-plus. 三条查询接口（Russell 常用的对话流程）

Russell 典型会问「接下来练什么模块／什么知识点？这个知识点下的题型覆盖全面吗？
全面就均衡分配出题」。对应三步，不用读代码，直接调：

```bash
# ① 推荐练什么（既有）：弱项、到期回捞、同族冷却
python3 /home/ubuntu/ExamSystem/scripts/learner_snapshot.py --compact

# ② 这个知识点下的题型覆盖全面吗
python3 /home/ubuntu/ExamSystem/scripts/kaodian_profile.py --coverage '最值'
#   输出：N 标签 / 卡内 M 条 · 已按考法拆分|尚未拆分
#         每个标签的 题数 / 练习次数 / 掌握度
#         尚未拆分时列出卡内条目，由你判断是并列步骤还是可拆考法

# ③ 覆盖全面 → 均衡分配出题（弱项和低库存优先，自动跳过旧的合并标签）
python3 /home/ubuntu/ExamSystem/scripts/kaodian_profile.py --plan '最值' --count 10
#   直接输出 {"slots":[...]}，原样塞给 --blueprint
```

串起来就是一条命令：

```bash
BP=$(python3 /home/ubuntu/ExamSystem/scripts/kaodian_profile.py --plan '最值' --count 10)
python3 /home/ubuntu/ExamSystem/scripts/quiz_lite.py --module '数量关系' \
  --batch-id '20260914_hermes_最值均衡_01' --blueprint "$BP"
```

`--plan` 只负责配题量，想再加命题侧重就往槽位里补 `brief` 后再传。
`--coverage` 不带关键词是全景（约 190 行），带关键词（模块名、卡片名或考点词）可收窄。

### 2c. 词表里没有这个考法？当场扩

考点词表**不是封闭字典**。复盘或讲题时发现一个有独立定义、独立解题动作、
现有二级标签又装不下的考法，直接登记，登记完当场就能用它出题：

```bash
python3 /home/ubuntu/ExamSystem/scripts/kaodian_profile.py --register \
  '数量关系-数学运算-行程问题-多次相遇与环形追及' \
  '数量关系' '数学运算' \
  '第N次相遇(2N-1)S；环形第N次追及N圈；与基础行程区分（新补录）'
```

- `--register` 收下已有 L3 下的 L4 子考点，并保存定义；重新登记同一标签更新定义，不增加作答样本。已确认的旧名仍按别名归一；
  登记后 `canonicalize` 就以它为准，`--tag` / `--blueprint` 立刻可用。
- 新点以 attempts=0 进画像，不污染快照（快照只看 attempts>0）。
- 什么时候才算新点：有独立的识别信号 + 独立的考场动作。只是换个说法、
  或同一动作的不同场景，合并到已有标签，不要新增。
- 子考点名用短而具体的复习词；登记末尾参数写清来源、定义、识别信号、解题动作和相邻边界。新 L4 不登记不得直接用于出题。
- **资料分析是封闭词表，不能这样扩**；图形推理/科学推理也不走本入口。
- 登记定义立即参与出题和审核，覆盖/配题查询也立即可见；不需要手动同步解法卡才能生效。稳定后可补充解法卡的教学内容。批次会保存当时口径，后续改定义不倒改历史试题。

### 3. 回复

```
已入库 5 题，批次 20260910_hermes_相邻不相邻_01
去 ExamSystem → AI 练题。
```

`rounds` 里的补题轮次、`seconds` 这些是给排查用的，不用报给用户。

## 资料分析：共享材料与确定性图表

纯文字单题可用 `quiz_lite.py`，每题须自带全部数据。需要共享材料、表格或柱状图时：

```bash
python3 /home/ubuntu/ExamSystem/scripts/ziliao_parallel_runner.py \
  --tag '资料分析-ABRX类-增长量计算与现期推算' --count 5 \
  --difficulty mid --materials 1 --formats chart
```

- 支持 `--blueprint` 编排，标签仍使用资料分析白名单，`brief` 指定细分情形，不新造资料标签。
- 题量 1–20，每篇 1–5 题，材料 1–4 篇；`--formats` 按篇传 `text,table,chart`，chart 为程序渲染柱图。
- 未指定批次号时自动分配唯一编号；显式编号重复则拒绝，不覆盖原题。
- 先冻结材料与图表数据，程序渲染，再独立出题，沿用已有正确性/内容/视觉质检后入库。
- 默认 mid；难度可选 easy/mid/hard。不因资料题使用图表就归入实验图题。
- 同样后台运行并等待完成通知，失败如实报告，不手写题或手动绕过闸门。

`quiz_generator.py --experimental-images` 仅保留开发实验文件输出，返回 experimental；不审核、不入库，不能向学员宣称题目可用于训练。

## 政治理论、常识应用：先核验原文再出题

执行口径见 `references/politics-common-workflow.md`。这两个模块复用 quiz_lite，强制权威原文快照、独立逐项核验。不要调旧 quiz_generator 绕过原文检查。

```bash
# 只点模块时：政治默认10题、常识默认5题；也可传count、tag或blueprint
python3 /home/ubuntu/ExamSystem/scripts/quiz_lite.py --module '政治理论' --batch-id 'YYYYMMDD_hermes_政治理论_01'
python3 /home/ubuntu/ExamSystem/scripts/quiz_lite.py --module '常识判断' --count 5 --batch-id 'YYYYMMDD_hermes_常识_01'
python3 /home/ubuntu/ExamSystem/scripts/quiz_lite.py --module '政治理论' --tag '政治理论-时事政治-重要文件' --count 3 --question-type multi --sources gd-science-literacy-2026 --batch-id 'YYYYMMDD_hermes_科学素质多选_01'
```

- 先读取 `policy_sources.py status`，按用户需求选对应原文；资料少时先用联网检索找到原发机关正文，再 `policy_sources.py add @资料登记.json`，由程序自己获取正文。不能自己编写资料正文或搜索摘要充当原文。
- 自动资料候选在 `data/manual-policy-sources/candidates.json`。候选未核验，不能直接出题；每周第一次政治/常识出题前梳理候选，新热点相关才登记，不把所有新闻塞进练习。
- 蓝图可逐槽传 `question_type: judge/single/multi`；政治整模块默认4判断+4单选+2多选，这是2025/2026回忆版训练结构，不是2027官方承诺。专项可自由指定题型与比例。
- `--sources id1,id2` 选择1–8份资料；`--as-of YYYY-MM-DD` 限制资料发布日期；新题默认今天。时政主攻近一年重要内容，但基础理论和仍适用的重要文件不过期删除。
- 默认模块蓝图只是启动组合，Hermes根据真题分布、学习证据和用户要求重新编排；不要长期只刷初始种子资料。
- 新知识点可讨论后登记；政策文件是证据，不是每篇都新造知识点。资料分析和其他模块原有入口不变。

## 科学素质文件对其他模块的影响

2026-09-23公布的广东科学素质方案作为选材依据，未宣布2027题量变化。
言语可用科普、科技伦理、AI应用的原创材料，但答案必须从文段推出，不把政策记忆当阅读能力；
逻辑可用科技实验、证据与因果场景，不依赖题干未提供的专业常识；
数量可采用科技产业情境但锁定用户指定数学考法；资料分析可用产业/研发/能源模拟统计，仍要求数据自洽与程序图表。
不得把所有练习强行换成AI主题，不提高未授权题量与难度，不据推测增开科学推理图题。

## 禁止

- 为找入口无目标翻长参考、自己拼题目草稿、自己跑闸门；本技能明确要求的原文与工作流资料须按需读取
- 工具失败后改写题目再发
- 把日练 图形5+逻辑15 套进专项小卷
- 没听清录音就改出快照里的「下一步候选」
