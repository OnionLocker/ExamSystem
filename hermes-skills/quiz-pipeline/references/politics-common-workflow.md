# 广东政治与常识：资料驱动出题

## 原文登记与动态更新

用户可以直接说“政治来10题”“常识科技5题”“只练矛盾原理”“根据这份文件练多选”。
Hermes完成选标签、找原文、确认口径、编蓝图、后台调用；不要让用户填写程序参数。

先 `python3 scripts/policy_sources.py status` 看资料；精确知识点无足够依据时联网检索发布机关、政府网、人大、主管部门、求是或权威学术机构。只接受可提取正文的HTTPS原文。
登记JSON可写到 `data/manual-policy-sources/spec-*.json`，例如：

```json
{
  "id": "official-topic-2026",
  "title": "原文准确标题",
  "url": "https://www.gd.gov.cn/原文路径",
  "published_at": "2026-09-23",
  "kind": "policy",
  "scope": "as_published",
  "tags": ["政治理论-时事政治-重要文件"],
  "focus": ["原文中要保留的段落关键词"]
}
```

然后执行 `python3 scripts/policy_sources.py add @data/manual-policy-sources/spec-*.json`（传具体文件名）。程序抓取原文并保存段落、校验哈希、核验时间。focus只做原文段落选择，不写AI概述。需要法律全文时不要只用条号前缀筛选，会漏掉续款。
缓存原文的 `paragraphs` 是 `[{"id":"p-…","text":"原文"}]` 数组，阅读时取每项的 `text`，不是字符串数组；批次生成失败先读错误和 `attempt-*.json`，不要猜文件结构或反复重跑。
读取某份已登记资料使用 `python3 scripts/policy_sources.py show <来源ID>`，输出完整缓存原文和段落ID。不要猜 `sources.json` 路径或调用不存在的 `get_source()`；`sources.json` 仅是生成批次内的资料快照。
联网查新读页面用 `python3 scripts/policy_sources.py inspect '<HTTPS地址>'`，直接返回正文与链接；读原文和发布栏目后再登记。无需搜索源码研究内部函数。HTTP 200或字节数仅证明能访问，不证明没有修订或替代。
kind可用foundation/policy/law/event；法律另填effective_at。默认as_published，题干明确依据具体文件/日期；current仅在核实当前效力与适用日期后使用。废止或被替代的资料登记expires_at或superseded_by，不能拿旧法答现行法问题。

每日任务更新已登记原文并发现官方栏目候选；抓取正文变化只说明需检查，不能自动宣称政策改变。每次动态出题时由Hermes检查当日查新核验状态，过期时审阅官方最新发布及版本差异；确认后登记新源或替代关系。未验证候选不能参与出题。
程序限定动态资料1天、基础资料7天内正文复核，超过即在出题前刷新。动态来源另须24小时内完成更新核验，网页重抓不会续期该记录。联网失败报错，不把缓存改写成新日期。来源冲突时暂停该考点，明确缺少什么资料。
运行中的每日任务为用户级 `examsystem-policy-refresh.timer`，每天北京时间06:15更新；安装样例在 `scripts/systemd/`。`refresh-status.json` 记录抓取结果，`candidates.json` 记录候选和发现错误。定时任务不自动生成练习，也不能自动判断所有法规的现行效力；新增、替代和冲突须由Hermes核实。

## 题型与广东风格

2025、2026本地回忆版：政治4判断+4单选+2多选，常识5单选。2024政治类内容仍放常识应用，不能把跨年旧栏目和题量直接当当前结构。
2025结构化试卷答案由同卷解析PDF补齐；真题样本与解析均为回忆版，不冒充官方公布。
生成器用2025题面学习风格、2026题面核对风格，两者不作为时政真值来源。最新事实只认资料包原文。
答案编码统一：判断A正确/B错误，单选A–D，多选完整排序集合。多选少选、错选不得分。
未指定题型时，政治10题采用4/4/2，5题采用2/2/1；1题默认为单选。用户指定题型或蓝图优先。默认模块小卷只基于已登记种子主题，用户要求覆盖更广主题时必须先补充来源，不能把种子主题当作完整考纲。

基础理论与政策并重。标准表述、哲学关系、党史、引文古语理解都保留；常识保留法律、科技、经济、史地人文。热点优先是学习策略，不是押题概率。
政治时事/广东文件要明确主体、程度、条件、范围；常识科技要分清科学事实、政策目标、已取得成就。用错主体或改一处概念可形成干扰，不能捏造真实机构的政策原话。
“未见原文提到”不能证明事实为假。负向设问需要每项解释是否符合设问，不能把真项误当错误答案。
“超过25%”可以推出“超过20%”；上下限或量词不同不必然构成错项。除精确原文阈值设问外，禁止把仍被原文蕴含的弱化表述当错项。easy是直接识记，mid需要条件或概念辨析，不能拿冷门记忆冒充中难度。

## 掌握度与复盘

沿用mastery-assessment规则，只记真实首次作答。原文刚学习完、有提示时标assisted；无需每题有草稿，口头复述原理和排除依据可以作为explanation证据。
判断/单选/多选分别观察；全是判断题的证据不足以认证掌握，多选不拆成四个样本。系统按同日相同原文证据合并重复支持，Hermes仍用template记录同考法换皮情况。
讲解逐项指出正确依据、漏选/误选原因，并引用报告里的来源；不靠“绝对词必错”“看着正能量”选答案。
原文更新仅提示相关知识需复测，保留原题时点、原答案和历史作答，不追溯改分。新题使用新版，旧卷复盘必须沿用当时资料。

## 其他模块

科学素质文件提高科技选材优先级，不改变数量考法、阅读答案依据、逻辑推理条件或科学图题边界。
申论可积累这些原文中的治理案例与政策措施，按用户任务讨论；此次没有新增自动申论评分或面试预测功能。

## 2026-09-25 实施口径：难度放宽，查新不放宽

政治、常识未指定难度默认auto，easy/mid/hard只作命题倾向，不因边界不同退题，也不强求两个竞争错项。基础识记有训练价值；实际难度取盲解/考官较低档保存。卷名保留请求档位，未指定为综合。题型、考点、答案集合、解析及每项原文证据仍必须成立。只用gemini-3.8-flash-high。

### 每次出题的查新动作

1. `policy_sources.py status` 查看 `update_review_due`；先按当前目录和用户要求选来源，不以种子资料代表完整知识库。科技成就应使用科研机构/主管部门成果正文，不拿科普法律职责冒充科学原理。
2. 若动态来源核验过期，联网查看发布机关正式原文及最新发布栏目，检索同一文件的新发布、修订、替代、废止；区分正式文件、征求意见稿和解读。标题候选只用于发现，不是证据。来源冲突未解决时停止该考点。
3. 有新文件，先 `add @...` 抓取登记；被替代来源通过同ID的登记更新保留 `superseded_by` / `expires_at`，不要删除历史快照。现行法律必须明确effective_at，并有当天核验依据；否则按文件注明时点命题，不声称“现行”。
4. 实际完成核对后，将 `{"source_ids":["来源ID"],"urls":["已读的权威原文和最新发布栏目HTTPS地址"],"findings":[{"url":"同上URL","quote":"从inspect输出逐字复制20至500字连续正文","finding":"该段说明的具体版本、日期、更新线索或适用范围"}],"note":"具体核对了哪些新旧版本、适用日期及处理结论"}` 保存至 `data/manual-policy-sources/`，执行 `python3 scripts/policy_sources.py review-updates @<文件>`。每个URL都须有finding，引用只取相关正文或栏目条目，不摘页脚充数；程序重抓并核对摘录。不把网页可访问当作无更新的证据，不以未见替代公告断言所有现行效力；按已核对版次命题。每次最多8个URL，相关来源可一起核验。
5. 使用 `--sources id1,id2` 选择本批真正相关的1–8份资料；未指定时程序先覆盖所有槽位，再补近期相关来源，不会因注册库超过8份就失败。资料截止日、原文版本和更新核验随批次保存。新入库另查过期/替代/正文变化；历史回执验证不因此失败，不倒改旧题评分。

必查文件：中央最新重要会议及正式文件、国家与广东现阶段五年规划纲要、当年国家与广东政府工作报告。每个新年度/新届次/新规划期重新检查，不能沿用固定清单冒充最新。广东与全国科技素材提高选材优先级，但不挤占用户指定考点，也不推断未来考纲比例。讲清“原理、用途、成果、进展阶段”，不把目标当成果，不把线索当定论。

`discover`保留未处理旧候选及首次/最近发现时间，已登记原文标记registered。定时任务只刷新与发现，不自动确认新旧政策效力。科普/科研栏目也是候选入口；不能因为模型给了引文就放弃核对引文是否真正支持答案。
