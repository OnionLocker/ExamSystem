# 质量闸门细则

正确性闸门只保证「答案唯一」。用户要的另外三条——**有意义、接近公考、考察到知识点**
——是这道闸门的事。

一道答案唯一但毫无意义的题，用户做完只是浪费时间。典型废题长这样：

- 用「甲乙丙丁」「A公司B部门」堆砌，没有真实场景
- 干扰项一眼就不像话，凭语感就能排除三个
- 靠生活常识就能猜对，完全不需要用到考点
- 一道题塞三个考点，做错了不知道错在哪
- 题干只有一行，跟真题的信息密度差太远

---

## 六条评分项

每条 0-2 分（0 不合格 / 1 勉强 / 2 合格），**总分低于 10 分或任何一条为 0 就打回**。

### 1. 考点单一且明确（0-2）

一道题只考一个考点，且必须是 Step 0 声明的那个。
考点复合（比如既考逆否又考真假话）算 0 分——用户做错时无法定位薄弱环节。

### 2. 载体真实或符合题型原生形态（0-2）

逻辑判断和应用题采用现实、自洽且信息有效的载体，例如研究论证、单位安排、
政策评审、项目立项、工程生产和日常科学现象。为了凑“公考味”写长故事但删掉背景
仍是裸算式，算 0 分。

数字推理、图形推理等原生无场景题不必硬套故事；排列约束题使用甲乙丙丁本身不是
缺陷，但若抽象符号导致规则不可读、现实关系荒谬或常识直接泄露答案，才打回。

### 3. 干扰项有诊断价值（0-2）

**这一条最重要。** 每个干扰项必须对应一个**典型错误类型**，
并且在解析里写明它钓的是哪种错。

翻译推理的四种典型错误，干扰项应该覆盖其中三种：

| 错误类型 | 干扰项怎么设 |
|---|---|
| 肯定后件 | 给一个 `B -> A` 形式的选项（原文是 `A -> B`） |
| 否定前件 | 给一个 `!A -> !B` 形式的选项 |
| 方向搞反 | 把「只有…才…」当成「如果…就…」翻译后的结论 |
| 漏了传递 | 只走一层链就停下的结论 |

其他模块按 `reference-style-principles.md` 的对应章节识别错误路径。四个选项里有两个
是同一种错误类型的，算 1 分；有干扰项不对应任何典型错误（纯粹瞎写），算 0 分。

### 4. 不能靠常识猜对（0-2）

不看决定性条件时，四个选项应当局部都像公考选项。如果凭生活常识、语感、
绝对词、单位格式或者「哪个选项最长」就能选出答案，0 分。

逻辑题可把关联词遮掉，言语题可只看四项外观，数量题可比较单位与数量级，事实题可看
是否只有一项语气克制。若不做目标考点也能猜中，就是废题。

### 5. 难度可控且标注（0-2）

翻译推理按链条层数分级，题干条件 2-4 条：

| 难度 | 链条 | 条件数 |
|---|---|---|
| 基础 | 两层（A->B->C） | 2 条 |
| 进阶 | 三层 | 3 条 |
| 拔高 | 四层，或含「除非」「且/或」 | 3-4 条 |

必须在 `difficulty` 字段标出来（1-5）。
一批题里全是同一难度算 1 分，难度混乱不标算 0 分。

### 6. 题干信息密度接近同类真题（0-2）

禁止对所有模块套一个“50–150 字”阈值。先读取
`references/reference-style-profile.md` 中相应 `category｜sub_category` 的
**广东目标分位**（不是全库混合，也不是国考拔高分位），并与独立 `evaluate` 参考包对照：

- 落在 P25–P75 且认知步骤、必要信息量相当：2 分。
- 稍超分位但每段信息都有解题作用：1 分。
- 明显短于同类广东真题、靠一句口号或裸条件就能答；或明显长于广东分位且在注水：0 分。
- 若 generate 包含国考样本，而本题比其中最浅的国考少一步关键推导或少一个可命名错因：0 分。

例如当前样本里逻辑判断题干中位数约 156 字，片段阅读约 243 字，数字推理约 20 字；
把它们统一裁成 50–150 字反而会制造假题。

## 硬性打回项：语义一致与考点信息边界

以下任一项出现，不看总分，直接 `REJECT`：

1. **题干、选项、答案、解析的对象或方向不一致。** 几何题必须逐字核对长边/短边、平行/垂直、内/外、半径/直径；日期题必须逐项核对年份、月份、起止日和“第几天”的口径。任何“题干说 A、解析按 B 算”的题直接废弃。
2. **题干存在歧义表达。** 禁止“沿长边中线”“沿短边中线”等可能有两种理解的口语，必须写成“沿平行于长边且平分短边的直线”等唯一几何关系。
3. **把目标考点作为提示直接送出。** 出题前先列出本题要考的所有子考点；属于目标子考点的事实不得在题干括号中提示。日期题若要考星期推算、平闰年判断、大小月，就使用具体年份和日期，不得再写“某日是星期几”“该年为平年/闰年”“某月共 31 天”。只有当这些事实不是本题考点时才允许给出。
4. **解析使用了题干没有的额外假设。** 代码算出答案不等于题目合格；验算输入必须与题干逐项一致，禁止在代码或解析中偷偷补条件。
5. **题图泄露推导、制造歧义或不符合考试可读性。** 题图只能包含 `IMAGE_FACTS`，不得出现 `MUST_DERIVE`、答案特征或解题步骤；默认使用紧凑黑白线稿。命题人视角与考生视角任一视觉审查未通过，直接废弃。
6. **已知即答案，或主语泄漏结论（R029）。** 翻译推理正确项不得复述、同义改写题干「已知/现已知」实例；主语须保持「某企业/某团队」，不得写成「已入驻的团队」「免于查验的货物」。一次逆否或选言否定肯定可以通过；零步回声必须打回。
7. **判断 / 科学配比错（R030）。** 成套判断推理 20 题必须是图形 5 + 逻辑 15，不得夹带科学推理；科学推理是独立 5 题且生物/地理/物理均衡、每题带图。不得整套翻译，也不得把科推压进判断卷后 5 题。

质量审查时必须先输出：
`HARD_FAIL: <NONE / 语义不一致 / 表述歧义 / 泄露考点 / 偷补条件 / 题图泄露 / 题图歧义 / 已知即答案 / 主语泄漏>`
只有 `HARD_FAIL: NONE` 才进入六项评分。

## 质量审查者 prompt 模板

正确性通过后，派**一个**独立 agent（这一步不需要两个）。
这次可以给它答案和解析——质量评估需要看到完整题目。
审查者必须独立读取 `references/quality-feedback.md`；如果无法读取，质量闸门不得判为通过。

```
你是公考题目质量评审。下面是一道已经通过逻辑正确性验证的题，
现在只评估它的「出题质量」，不需要再验算答案。

先读取：
- /home/ubuntu/.hermes/skills/kaogong/quiz-pipeline/references/quality-feedback.md
- /home/ubuntu/.hermes/skills/kaogong/quiz-pipeline/references/reference-style-principles.md
- /home/ubuntu/.hermes/skills/kaogong/quiz-pipeline/references/reference-style-profile.md

然后独立运行 `/home/ubuntu/ExamSystem/scripts/reference_style.py context --role evaluate`
（传入本题 category / sub-category / 规范主标签，取 1–3 道），实际读取返回的留出真题；
带图题必须打开返回的本地图片。禁止使用命题者的 generate context。
独立列出两张内部清单：
- FACTS：题干直接提供的全部事实；
- MUST_DERIVE：本题要求考生自行识别或推出的事实。
逐项检查解析是否只使用 FACTS 或合法推导，MUST_DERIVE 是否被题干泄露，并对所有有效回归规则逐条判定。不要相信出题者的自评。

按六条评分，每条 0-2 分，逐条给分并写一句理由：

1. 考点单一且明确（声明考点：<考点>）。考点复合给 0。
2. 载体真实或符合该题型原生形态；无效长故事、荒谬规则给 0。
3. 干扰项有诊断价值。每个干扰项要对应一种典型错误（肯定后件 / 否定前件 /
   方向搞反 / 漏了传递）。有干扰项不对应任何典型错误给 0。
4. 不能靠选项外观、常识、语感、绝对词、单位或长度猜对。
5. 难度可控且已标注。
6. 题干信息密度与同题型 profile 分位及 evaluate 真题相当，不套统一字数。

先单独输出硬性检查：
HARD_FAIL: <NONE / 语义不一致 / 表述歧义 / 泄露考点 / 偷补条件 / 题图泄露 / 题图歧义 / 已知即答案 / 主语泄漏>
REGRESSION_FAIL: <NONE / 命中的 R 编号，逗号分隔>

最后两行只输出这个格式：
EVAL_CONTEXT_ID: <refctx-...> | EVAL_REFERENCE_IDS: <逗号分隔 external_id>
SCORE: <总分>/12 | ZERO_ITEMS: <得 0 分的条目号，逗号分隔，没有就写 NONE> | HARD_FAIL: <同上> | REGRESSION_FAIL: <同上> | VERDICT: <PASS/REJECT>

判定标准：总分 >= 10、ZERO_ITEMS 为 NONE、HARD_FAIL 为 NONE 且 REGRESSION_FAIL 为 NONE 才是 PASS。

题目：
<完整题目，含答案与解析>
```

### 裁决

- `VERDICT: PASS` -> 质量通过，进 Step 4 交付
- `VERDICT: REJECT` -> 按 `ZERO_ITEMS` 和低分项改，重跑**两道闸门**
  （改了题干或选项，正确性可能已经变了，不许只补质量）

## 各题型的额外质量要求

### 言语理解与表达
- 材料要有明确的行文脉络（总分、分总、转折），不能是拼凑的句子
- 选项不能出现「表述过于绝对」以外的低级破绽（那太容易排除）
- 优先从现成真题库抽，自制的质量很难达标

### 数量关系
- 数字要能整除、结果要是整数（人数、次数、天数），不要出现 3.7 个人
- 干扰项应该对应典型计算失误：少算一步、单位没换、算成了差而不是比
- 几何变形必须把切割线方向和尺寸变化写成唯一解释，并逐字核对题干与解析；禁止使用“长边中线/短边中线”这种歧义简称
- 日期题先声明要考的子考点。若考平闰年、大小月或星期推算，题干只给具体年份和日期，不得用括号直接提示“平年/闰年”“共31天”或起始星期

### 带图题（图形推理 / 科学推理 / 几何）
- 写图前先列 `IMAGE_FACTS` 与 `MUST_DERIVE`，生成提示词只能包含前者
- 风格默认白底黑线、少量必要虚线和题干已有标签；禁止彩色分区、渐变、装饰图标、教学标题和解题流程箭头
- 图片按真实试卷的紧凑尺度设计；主体四周只保留少量白边，文字与线条缩小后仍可辨认
- 生成后必须启动两个独立视觉审查：命题人审“符合意图且没有多画”，考生审“看得懂、无歧义、可独立作答”；两者都通过才进入普通质量评分

### 资料分析
- 材料数据必须自洽（各分项加起来等于总数、增长率和基期现期对得上）；数字是模拟数，用来练知识点
- 一道题只问一个量，不要「既问增长率又问比重」
- `tags[0]` 必须是知识库主标签（`07-ziliao.md`），默认 4 篇 × 5 题按画像组合，不要写 `资料分析-综合分析-综合判断`
- 广东 4 篇形态要齐（文字 / 表 / 图 / 选项图）；表/柱/饼用渲染脚本；未点名不要拔高
- 4 篇答案须恰好 3 篇为 ABCD 各一 + 1 随机，1 篇打散；先算定值再排到指定字母
- 干扰项要覆盖「基期现期搞反」「增长率当增长量」这类典型错误

### 常识判断
- 只出有确定答案的事实题，不出有争议的
- 法条类必须核实到现行有效版本
- 不出纯记忆冷知识，要考到高频考点

## 一个提醒

这道闸门是模型判断，不是决定性的。
它能挡住明显的废题（抽象符号、干扰项瞎写、常识可猜），
但挡不住「看起来什么都对、就是没意思」的题。

所以真正的质量兜底还是用户反馈：用户指出问题时，按 `references/quality-feedback.md` 的格式抽象成跨题型回归规则，扫描当前批次，并让后续写题与独立盲审都执行。不要辩解，也不要只修那一道题。
