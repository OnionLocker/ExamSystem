# 讲解配图

**唯一画图方式**：`python3 /home/ubuntu/ExamSystem/scripts/draw_diagram.py`，JSON 规格从标准输入传入。
完整模板字段和例子在 `/home/ubuntu/ExamSystem/hermes-skills/gd-gongkao-coach/references/diagram-drawing.md`，第一次画先读它（只读这一个文件）。

## 流程（不查数据库、不读源码、不找别的技能）

1. 直接按你掌握的知识点内容组织讲解。用户提到某场练习的题时，题目以用户消息或报告为准。
2. 每个需要图的考法，选一个模板（选法见说明文件里的对照表）：
   - `venn2` / `venn3`：集合重叠，如容斥
   - `bar`：部分与整体，如反向极值、比例、工程分量
   - `line`：直线上的行程、年龄、植树
   - `circle`：环形跑道
   - `slots`：排列组合的捆绑、插空、隔板
   - `tree`：概率分步、分类计数
   - `chain`：翻译推理链
   - `cross`：十字交叉求混合比例
   - `grid`：样本空间、匹配推理打勾表、日历
   - `gantt`：工程交替、统筹安排
   - `geometry`：平面几何（阴影面积、勾股、扇形）、立体几何（长方体切割、圆柱）。坐标按题目真实尺寸取，边长、角度、面积都写 `check`
   言语理解、资料分析图表不在这里画（资料分析图表另有现成工具）。
3. 每张图调用一次脚本，`--slug` 用英文/拼音短词：

```bash
python3 /home/ubuntu/ExamSystem/scripts/draw_diagram.py --slug rongchi-two-sets <<'EOF'
{"template":"venn2","title":"两集合：交集数了两次","names":{"A":"骑车 18","B":"游泳 15"},
 "sets":{"A":18,"B":15},"total":30,
 "regions":{"a":10,"b":7,"ab":{"v":8,"text":"都会\n8","role":"key"},"none":5},
 "notes":["30 − 5 = 18 + 15 − 8"]}
EOF
```

4. 成功返回 `{"ok": true, "markdown": "![...](/q-images/diagrams/...svg)"}`：把 `markdown` 原样单独成段放进回答，紧挨对应讲解。
5. 返回 `{"ok": false, "errors": [...]}`：是你的数字对不上，重算后改规格再画；两次失败就不放这张图，正文照讲。

## 排版

- 图片 Markdown 单独成段，紧挨它要说明的那段讲解。
- 重要公式（核心模型、定义式、要背的结论）单独成行写 `$$…$$`，前后各空一行，网页会给它加公式底并居中；列表里的公式行缩进到和列表文字对齐。代入计算可以留在行内。
- 题型分类、“先看特征再选考法”的分流图、难度梯度、考场全景图谱、知识框架总览，一律用 `tree` 画（`levels` + `result_title` + `legend: false`），口诀/用时放 `result`。禁止用代码块、`├──` `└──` `│` 树形字符或方框线拼。超过 16 个叶子就按梯队拆成 2–3 张图。

## 禁止

- 图里的文字用 LaTeX 或上下标字符：排列组合写 `A(4,2)`、`C(9,2)`，分数写 `3/5`。
- 自己写 HTML、SVG、Canvas 文件，或给 `file://`、本地绝对路径链接（用户浏览器打不开）。
- 用 ASCII 方框字符、表格、Mermaid 拼示意图。模板表达不了就不画。
- 为了画图去查 exam.db、fenbiTree、knowledge-content 目录或 src/server 源码。
- 图形推理、空间推理、科学推理出题。本技能只画讲解示意图。

## 用量

一次回答 0–4 张：讲完整知识点时每个考法一张；单题讲解一张；一行公式能算完的不画。
