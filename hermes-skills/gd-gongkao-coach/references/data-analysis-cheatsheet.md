# 资料分析核心速算公式与陷阱防范速查表

## 一、 统一符号与考场物理口径（R1/R2体系）

资料分析除法比值统一表示为商式 $C = \frac{A}{B}$（$A$ 为分子，$B$ 为分母）：
- **$R_1$ 焊死为分子（部分）增长率**
- **$R_2$ 焊死为分母（整体）增长率**
- 隔年与乘积结构中：$R_1$ 为现期/今年增速，$R_2$ 为前期/去年增速。

---

## 二、 核心公式速查与秒杀动作

1. **两期比重差**：
   $$\text{比重差} = \frac{A}{B} \times \frac{R_1 - R_2}{1 + R_1}$$
   - **定性定升降**：$R_1 > R_2 \implies$ 比重上升；$R_1 < R_2 \implies$ 比重下降。秒排两项。
   - **定量卡上限（秒杀）**：只要现期比重 $\frac{A}{B} < 1$，两期比重差绝对值**严格小于 $|R_1 - R_2|$ 百分点**！直接看选项秒杀，绝不在考场做长除法。

2. **比值增长率 / 平均数增长率**：
   $$r_{\text{比值}} = \frac{R_1 - R_2}{1 + R_2}$$
   - **防呆锚点**：“均前每后做分母，分母增速配在下”。分母是 $B$、分母增速是 $R_2$，因此分母必须是 $1 + R_2$，绝不能错写成 $1 + R_1$。

3. **基期比重**：
   $$P_{\text{基}} = \frac{A}{B} \times \frac{1 + R_2}{1 + R_1}$$
   - 分子上乘的是整体增速 $(1 + R_2)$，分母下乘的是部分增速 $(1 + R_1)$。

4. **隔年与乘积增长率**：
   $$R = R_1 + R_2 + R_1 \times R_2$$
   - 隔年跨期（今年 $R_1$，去年 $R_2$）与乘积联动（$A = B \times P$）形式完全相同。
   - 逆算去年增速：$R_2 = \frac{R_{\text{隔}} - R_1}{1 + R_1}$。

5. **增量比重**：
   $$\text{增量比重} = \frac{\Delta A}{\Delta B} = \frac{A}{B} \times \frac{R_1}{R_2} \times \frac{1+R_2}{1+R_1}$$
   - **放缩秒杀定性**：若 $R_1 > R_2$，则 $\text{增量比重} > \text{现期比重} \frac{A}{B}$；若 $R_1 < R_2$，则 $\text{增量比重} < \text{现期比重}$。
   - **坑点防范**：选项常将“现期比重”设为强干扰项。当 $R_1 > R_2$ 时，直接锁定大于现期比重的选项，无需繁琐精算。

6. **百化分算增长量（必背肌肉记忆）**：
   - 当增长率 $r \approx \frac{1}{n}$ 时：
     $$\text{增长量} = \frac{\text{现期 } A}{n+1} \qquad \text{减少量} = -\frac{\text{现期 } A}{n-1}$$
   - **微速口算**：$|r| \le 5\%$ 时直接算 $A \times r$。
   - **增量比较**：大大则大；一大一小看乘积 $A \times r$。

7. **混合增长率（杠杆线段法 / 十字交叉）**：
   - 整体增长率介于各部分之间：$R_1 < R_{\text{混}} < R_2$。
   - 偏向于基期量较大的一方。
   - **杠杆距离反比**：线段距离与**基期量（非现期）**成反比：
     $$\frac{B_1}{B_2} = \frac{|R_2 - R_{\text{混}}|}{|R_{\text{混}} - R_1|}$$
   - **致命陷阱**：十字交叉交叉出的比例物理本质是**基期量之比**，严禁误套现期量！

## 三、 易错坑点与秒杀避坑
1. **乘积差值/双变量同向变动估算陷阱**：
   - 计算 $A \times a\% - B \times b\%$（如比较两年初选某项选项的总人数差）：
   - 当基数 $A > B$ 且 比例 $a\% > b\%$ 均在同向减少时，**总减少量等于“比例变动减少量”与“基数变动减少量”的叠加**：
     $$\Delta \text{总量} \approx A \cdot (a\% - b\%) + (A - B) \cdot b\%$$
   - **避坑**：切忌只计算 $A \cdot (a\% - b\%)$。临界值附近时，忽略基数下降导致的人数减少会导致误选。

2. **尾数法适用条件**：
   - 适用于加减法且选项末一位/末两位数互不相同的情况。
   - 减法注意借位计算，末位不一致直接看尾数秒选走人。

## 四、 数资屏幕心算与根治卡顿心法
1. **退位减法【凑整补数法】（消灭借位）**：
   - 心算大忌是“向高位借位”（导致工作记忆暂存过载，出现粗心/死机）。
   - **算法**：遇退位减法，将减数凑成整十/整百，采用“多减加回”。
   - **公式**：若减数 $B$ 接近整百 $M$（缺 $k = M - B$），则 $A - B = (A - M) + k$。
   - **示例**：$543 - 289 = (543 - 300) + 11 = 243 + 11 = 254$；$712 - 395 = (712 - 400) + 5 = 317$。

2. **进位加法【高位滚加法】（顺读顺加）**：
   - 抛弃纸笔竖式从个位向高位加的旧习惯。
   - **算法**：从高位向低位（百位 $\rightarrow$ 十位 $\rightarrow$ 个位）顺向滚动累加，保持与读数习惯一致，工作记忆只保留当前滚动值。
   - **示例**：$478 + 356 \rightarrow (400+300=700) \rightarrow (700+70+50=820) \rightarrow (820+8+6=834)$。

3. **心算训练 UI/系统设计纪律**：
   - 心算训练/练习界面切忌强制学员按“个位 $\rightarrow$ 十位 $\rightarrow$ 百位”顺向敲入答案（如误导竖式心算）；
   - 界面与算法必须支持高位优先输入与补数思维转换。
