# 申论 · 解题口径（广东省考）

> 用户报考县级，对应 2024 年起的县镇卷。2024–2026 年县镇卷、省市卷结构相同：150 分钟 / 100 分、8 份材料、三题——
> 归纳概括 20 分（不超过 200 字，限定一份材料）、提出对策 30 分（问题 + 对策，不超过 300 字，给身份）、文章写作 50 分（议论文，县镇 800–1000 字、省市 1000 字左右）。
> 2023 年乡镇卷另有综合分析、贯彻执行（发言提纲），题型特训也会出。
> 讲评一律按本卡步骤，分数以评分报告为准（`data/practice-reviews/shenlun/submission-<ID>.md`），判分口径与点评版式按 `shenlun-review-standard.md`；不临场另起一套讲法，不用国考套路替代。
> 阅卷口径与系统一致：**按要点采点给分**，一个意思一分到两分；套话、材料外的空话不给分。

## 通用三步（所有小题）

1. **审题定范围**：圈出作答对象（谁、什么事）、作答任务（做法 / 问题 / 原因 / 意义 / 理解 / 对策）、材料范围（“给定资料几”）、字数。
2. **逐段找点**：只在指定材料里找；每找到一个点，在材料上标序号。一句话里有几个独立意思就记几个点，不合并。
3. **归类成条**：同类点合并成一条，每条「总括词 + 具体内容」，条与条用一、二、三分开；先写分量重的。

## 归纳概括

- 识别：问「概括……做法 / 问题 / 成效 / 经验 / 特点」。
- 步骤：通用三步；关键词要用材料原词或规范概括，不写「加强管理」这类空泛词。
- 禁止：加入材料没有的做法；写成分析或对策。

## 综合分析

- 识别：问「谈谈你对……的理解」「分析……的原因 / 意义 / 影响」。
- 步骤：
  1. 表态 / 解释含义（一句话，扣住引号里的说法）；
  2. 分析：结合材料讲「为什么 / 怎么体现」，每层一个材料依据；
  3. 落脚：提出启示或做法（一两句）。
- 禁止：只解释含义不分析；脱离材料泛泛议论。

## 提出对策

- 识别：问「提出解决对策 / 建议」。
- 步骤：
  1. 先找问题，再找原因（材料里的问题、群众反映、反面案例）；
  2. 一个问题配一条对策：「主体 + 措施 + 目的」；
  3. 材料里的好经验可以借鉴转化，但要落到本题对象上。
- 禁止：对策和问题对不上；只写口号；照搬与问题无关的经验。

## 贯彻执行

- 识别：「假如你是……请写一份倡议书 / 宣传稿 / 讲话提纲 / 简报 / 情况报告 / 方案要点」。
- 步骤：
  1. 定身份、对象、文种和目的；
  2. 格式要素：标题、称谓（有对象的文种）、正文、落款和日期（按文种取舍）；
  3. 正文 = 背景或目的一句 + 按材料要点分条 + 号召或结尾一句；
  4. 语气贴合对象（对群众通俗，对上级规范）。
- 禁止：漏格式要素；把公文写成议论文。

## 文章写作（议论文）

- 识别：「自选角度，自拟题目，写一篇议论文」，1000～1200 字。
- 步骤：
  1. 立意：从材料主旨和题目给定话题定总论点，**偏题直接掉档**；
  2. 结构：标题 → 开头引出总论点 → 三个分论点（并列或递进）→ 结尾升华；
  3. 每个分论点 = 论点句 + 材料或实例论据 + 分析（为什么、怎么做）+ 回扣；
  4. 字数写满下限，不足 1000 字会扣分。
- 档次（系统按立意、结构、论证、语言四维评档，立意定上限）：一类文 33～40，二类文 25～32，三类文 17～24，四类文 16 以下（40 分制）。
- 禁止：通篇口号无论据；分论点之间重复；只罗列材料不分析。
