# 政治理论 · 解题口径（广东省考）

> 2025–2026 稳定结构：第 1–10 题，共 10 题。
> 近年实测：判断题 4 + 单选题 4 + 多选题 2。国考政治全是单选，不要用国考讲法套广东。
> 内容重心：习近平新时代中国特色社会主义思想一家独大，其次党史党建、广东省情（改革开放/特区精神、制造业当家、百千万工程、粤港澳大湾区、新质生产力）。

---

## 共用原则（三类题都用）

1. **以最新权威表述为准**，不要用过时口号替换（如把「以经济建设为中心」的旧搭配套到新思想特有表述上）。
2. **主体、程度、范围、条件**四要素逐项核对。错一个就整句错。
3. **哲学题盯「根本 / 决定 / 本质 / 第一」**：这些词在马克思主义原理里位置固定，张冠李戴必错。
   - 社会发展的根本动力：社会基本矛盾（生产力与生产关系、经济基础与上层建筑）。
   - 生产力是人类社会发展的最终决定力量；不能说「生产关系是根本动力」。
   - 物质是标志客观实在的哲学范畴；运动是物质的根本属性。
4. **广东题看有没有把全国表述安到广东头上**，或把广东特色说成全国唯一。
5. 不会做时：先排绝对化错误项（凡是、全部、只有、彻底、唯一），再选最贴近原文精神的项。政治不是数量，禁止「蒙个顺口的」。

### 标签判断顺序

1. 题干直接引用理论名词或文件，优先归入“新思想与时政理论”；如果题目实际考的是其中的哲学关系，归入“马克思主义哲学”。
2. 题目问历史事件的时间、会议或党建要求，归入“党史党建”；不要只写“新思想”。
3. 出现广东地名、广东工程或广东政策落点，优先归入“广东省情”，全国性理论只作为关联知识点。
4. 一题只保留一个主标签，解析中可补 `关联知识点：...`，主标签必须与 `knowledge_points` 和画像记录完全一致。

## 一、判断题（正确 / 错误）

**识别**：题干标注「（判断题）」，无 A–D 选项，涂对/错。本库答案惯例：A=正确，B=错误。

**考场步骤：**

1. 画出绝对化词和「根本 / 首要 / 本质 / 必须」。
2. 把句子拆成「主语 + 判断 + 宾语」：主语对不对、判断词对不对、宾语对不对。
3. 对照新思想/党的文件的标准表述。一字之差往往整句错。
4. 常见设错手法（优先按这个清单查）：
   - 主客体对调（把「人民」和「党」的位置换了）
   - 根本与重要互换（「重要基础」说成「根本特征」）
   - 充分与必要互换
   - 把阶段性任务说成永恒本质
   - 哲学概念串台（生产力/生产关系、物质/意识、实践/认识）
5. 拿不准且句子像文件原话、没有绝对化词 → 倾向正确；有「根本/唯一/全部」且你觉得别扭 → 倾向错误。

**禁止：**把判断题讲成「这句话好不好听」。对错只看表述是否符合权威口径。

**真题锚点（2026）：**
- 「农业农村现代化关系中国式现代化全局和成色」→ 正确。
- 「生产关系是人类社会发展的根本动力，也是一切社会变迁和政治变革的终极原因」→ 错误（根本动力不是生产关系这一侧单独成立）。

**下次怎么做：**先砍「根本/唯一」，再对主语。

## 二、单选题

**识别**：四选一，题干常引总书记讲话、会议、战略，问「说明了 / 是指 / 正确的是 / 不包括」。

**考场步骤：**

1. 读设问：选是还是选非（「不正确」「不属于」立刻圈出来）。
2. 读材料找**题眼**（一段话里被解释的那个概念，如守正创新、碳达峰、宪法与经济基础、节水优先）。
3. 选项逐条验证：
   - 原文有没有说过
   - 程度是否加码（「有利于」变成「就能」）
   - 对象是否偷换（把「文化」答成「经济」）
4. 引文题：答案必须能回扣引文中的关键词，不要选正确但与引文无关的金句。
5. 四个都像对时：选**最具体、最能解释题干概念**的，不选正确空话。

**禁止：**用「都是正能量」来选。干扰项经常也是正确政策，只是答非所问。

**下次怎么做：**先圈设问的「是/非」，再让选项回到题干那个词。

## 三、多选题

**识别**：题干标注「（多选题）」，答案为两个及以上字母，如 BD、ACD。

**考场步骤：**

1. 把每个选项当成一道判断题，独立对错，不要「配齐三个好看」。
2. 广东行测多选按**全对才得分**处理：少选、错选都是 0。不确定的项，用「绝对化 / 主体错误 / 文件没这层意思」裁决，不要为了多选而多选。
3. 选项之间常是并列要点（思想路线的内容、物质范畴的规定、历史贡献的几个方面）。缺一个典型要点通常是漏选。
4. 含「只 / 才 / 仅仅 / 全部」的选项优先当错误项审。
5. 讲题时必须逐项说清：A 对在哪、B 错在哪，禁止只给最终字母。

**禁止：**「这题感觉选三个」。没有逐项判断就给答案，等于没教。

**下次怎么做：**四道判断题做完，再组合字母。

## 四、内容分层（老师备课用，讲题时按需抽）

讲题不需要把这一节背给学生听，但定位考点时按此检索：

| 层 | 考什么 | 典型设错 |
|---|---|---|
| 新思想 | 六个必须坚持、中国式现代化、新质生产力、以人民为中心、高质量发展、两个结合 | 把其中一个「必须坚持」换成日常口语 |
| 哲学原理 | 物质、实践、矛盾、生产力与生产关系 | 「根本/决定」用错对象 |
| 党史党建 | 思想路线（实事求是）、三大法宝、根本宗旨 | 历史时期张冠李戴 |
| 会议文件 | 二十大、二十届三中全会、中央相关工作会议、五年规划 | 把建议稿目标和已完成成就互换 |
| 广东省情 | 特区精神、改革开放排头兵、制造业当家、百千万工程、绿美广东、大湾区 | 把广东经验说成全国唯一发明 |

政治不靠题海，靠**标准表述敏感度**。讲题时点出「官方会怎么说」，不要扩展成思政课。
