# 言语理解与表达 · 解题口径（广东省考）

> 本文件按言语理解 PDF 重构。广东不启用国考文章阅读、词句理解、承接叙述；逻辑填空和片段阅读均按卡片固定动作执行。

## 固定动作

1. 先看设问，确定模块和题型。
2. 输出固定知识点标签：`本题考察知识点：模块-一级知识点-二级知识点`。
3. 按对应卡片的步骤写进 `#### 考场解法`；每个干扰项点名陷阱。排版走 `practice-review-spec.md`：对错分流，逻辑填空先锁第二空搭配、少长赏析；`#### 下次动作` 必须 `触发：… → 优先：…`。禁止把「下次怎么做」收成没有标题的一句。
4. PDF 未覆盖的新变体，先套最接近的母题型；确认有独立定义和动作后，按 `knowledge-point-extension.md` 补录。

广东题型路由：逻辑填空、中心理解、意图判断、标题拟定、下文推断、语句填入、语句排序、细节判断。逻辑填空先找逻辑对应，再做词语辨析；尾句推断继续按用户已验证的前句尾词方法。

## 题型卡片

### 片段阅读 · 题型文段分类与解题思路

**固定识别：**先看提问分辨题型和文段类型，再在句号处划斜线分析结构，预设答案后对比选项择优。

**考场步骤：**
- 先看提问：分辨题型（中心理解、标题拟定、下文推断、语句填入、语句排序、细节判断）及文段可能类型（说理类、科普介绍类、新闻类）。
- 再看文段：在句号处划斜线分层，宏观把握行文结构，微观抓逻辑关联词与指示代词；有重点则精炼浓缩、同义替换，无重点则全面概括、提取共性。
- 预设答案：核对选项与文段在话题和态度倾向上是否一致。
- 对比选项：运用两出处、六有误、四大类比对，结合一比较、一正确、一验证挑出答案，并验证主体、首句、高频词、关键词。

**知识要点：**
- 说理类文段：表达观点、看法、态度。原文有对策优先选对策（极少数改造成对策句）；有观点态度选观点态度；有问题可概括问题也可解决问题（无优先选择）。
- 科普介绍类文段：客观，选“中性”概括选项，不选对策与问题。
- 新闻类文段：具实时性，重视“新”（新状况、新成绩、新突破等）；常见结构为“背景+新”。
- 解题总原则：同义替换，对比择优；利用选项“挑”答案，允许瑕疵答案出现。

**下次怎么做：**拿到文段先读提问，在文段句号处划斜线切分层次。

**禁止：**
- 只见树木不见森林
- 在科普介绍类文段中误选对策与问题
- 忽略主体、首句、高频词、关键词验证导致低级错误

### 中心理解题 · 五种常见结构分析

**固定识别：**宏观切分层次，识别前对策、后对策、总分/分总、并列/大并列、二层结构5种模式找准主旨重点。

**考场步骤：**
- 判别文段结构类型：判断是对策型、总分型、并列型还是二层结构。
- 锁定重点位置：前对策看首句观点/对策；后对策看尾部对策/观点；总分/分总锁定“总”；并列提炼共性；二层结构提取核心层。
- 多对策/多选项甄别：若多个选项出自对策句，关注主体与必要条件；若出现多个不同对策，核对论证内容及所针对的问题。

**知识要点：**
- 常见话题引出方式：开门见山（首句定重点）、背景知识引出（背景不重要）、对比引出（紧跟观点/对策）、转折引出（紧跟观点/对策）、设问引出（注意后续回答）。
- 常见对策表述：祈使句（应当、需要等）；禁止性对策（不能、如果……就不……）；必要条件（关键、基础、前提、离不开、必不可少等）；关联词（只有……才……、必须……否则……、要……就……等）；语义对策（时代命题、重要议题、负有……义务、长远目标、必经之路、必然趋势、有助于等）。
- 5种结构模型：①前对策（引出话题/问题=>直接给对策/观点=>论证）；②后对策（引出话题/问题=>分析说明=>给对策/观点）；③总分/分总（“总”是重点，“分”为并列分论点或观点后分析）；④并列/大并列（提示词“还、也、另外、同时、另一方面”或按时间/地区/人物分段分类）；⑤二层结构（A+B结构，如转折、果因/因果、对比、设问+回答、背景+新发现/新成就/新变化/现状，尤其重视我国）。

**下次怎么做：**划分文段各层逻辑关系，圈出对策词、总述句或转折/因果核心句。

**禁止：**
- 误选论证、背景部分提炼的选项
- 说理类文段误选中性描述选项
- 忽略对策所针对的核心问题导致对策脱节
- 并列文段只见单方面以偏概全

### 中心理解题 · 关键信息抓取

**固定识别：**文段精读时重点抓取首句、全文主体及反复出现的高频词/核心关键词。

**考场步骤：**
- 读首句：提取首句中的主语和关键词，确定文段谈话范围。
- 审全文主体：提取首句和主旨句的主语，明确全文描述的核心主体。
- 抓高频词与关键词：标注文段中反复多次出现的词，以及观点对策句中的核心词。
- 比对选项：核对选项是否包含上述主体词与高频词，排除偷换主体或缺少核心词的选项。

**知识要点：**
- 重视首句：首句往往确定全文谈话范围。
- 重视主体：全文围绕的核心陈述对象，重点关注首句和主旨句主语。
- 重视高频词/关键词：高频词代表文段反复强调的中心，关键词代表观点对策的核心概念。

**下次怎么做：**读文段时用笔圈出首句主语、主旨句核心词及文段高频词。

**禁止：**
- 选项缺少文段核心主体词
- 误将背景信息中的非核心词当作主旨主体
- 选项遗漏反复出现的高频核心词导致概括片面

### 中心理解题 · 选项分析体系

**固定识别：**按“两不出、六有误、四大类、一比较、一正确、一验证”系统筛除错误项、锁定正确项。

**考场步骤：**
- 执行“两不出”排查：排除出处不对的选项。
- 执行“六有误”排查：排查片面、杂糅、绝对化、下定义、无中生有、本身有误。
- 匹配“四大类”文段结构：检查文段是否有对应篇幅结构，无对应结构不得选。
- 择优验证：运用“一比较”选具体、“一正确”选全面项、纠结时用“一验证”反推文段。

**知识要点：**
- 两不出：1. 背景、例子、分析论证中提炼的不选；2. “但是/因此/对策”之前、“不是...而是”的“不是...”、被指代部分提炼的不选。
- 六有误：1. 片面（并列关系只说其一不选，若选项为对策可包容）；2. 杂糅（拼凑原文词语不选）；3. 绝对化（原文未提最高级、必要条件时不选）；4. 下定义（中性表达、介绍说明在说理类不选）；5. 无中生有（关键信息未提及不选）；6. 本身有误（不符事实/主流价值观、逻辑错误不选）。
- 四大类（须文段对应结构才能选）：1. 原因类（重点大篇幅谈原因）；2. 具体类（能归纳概括出具体小点）；3. 历程类（清晰时间轴介绍全过程）；4. 区别比较联系类（双主语且篇幅相当）。
- 一比较：选具体选项（A能回答B，A具体）。
- 一正确：选“A且B”类概括非常全面的选项（高概率正确）。
- 一验证：两项纠结时，根据选项反推文段结构来核验。

**下次怎么做：**对照“两不出”与“六有误”逐一扫除干扰项，核对文段是否具备“四大类”对应结构。

**禁止：**
- 并列文段选片面项
- 把各句词语拼凑的杂糅项当概括项
- 无对应长篇幅时误选原因类/历程类/区别联系类选项

### 片段阅读 · 标题拟定

**固定识别：**将主旨意图进行标题化改造，重点寻找包含核心关键词、主语正确且具趣味性/力量感的选项。

**考场步骤：**
- 按主旨意图题方法提炼文段核心观点、对策或主要对象。
- 比对选项核心要素：标题必须包含核心关键词（可同义替换）、主语必须正确、必须体现作者观点或对策。
- 考量形式与吸引力：标题要有可读性、趣味性，对策类要有力量；重点关注带“双引号”的选项。

**知识要点：**
- 题型本质：主旨意图题的变型，将主旨意图进行“标题化”改造。
- 正确选项特征：包含关键词、主语正确、体现观点/对策、具可读性与趣味性、对策有力。
- 特征技巧：特别注意带“双引号”选项，其为正确答案的概率很高。

**下次怎么做：**提炼出主旨对策或核心词后，优先比对带有双引号及包含核心主语的精炼选项。

**禁止：**
- 缺少核心关键词或关键词片面
- 误选带有“启示”“以柔克刚”等无中生有概括词的选项
- 动作方向与文段相反（如文段强调“主动创造/造敌”，选项偷换为“乘隙/辨隙”）

### 片段阅读 · 下文推断

**固定识别：**将文段和下文看作整体套入行文脉络，紧盯文段首尾句，上文已介绍过的内容下文不再介绍。

**考场步骤：**
- 通读文段把握行文脉络，重点盯住尾句新话题或文段核心结构。
- 套入考法结构模型判断后文发展逻辑。
- 排除上文已详细介绍过的内容，以及脱离尾句核心问题的非针对性选项。

**知识要点：**
- 三种简单结构：①文末提新内容 => 下文解释新内容；②提出问题 => 下文分析问题/分析原因/解决问题（成功案例是对策的一种）；③给出宏观对策 => 下文给出具体对策。
- 三种不易识别结构：盯住文段首句（对比、转折、总分）。
- 避重原则：上文已经介绍过的，下文一般不再介绍。

**下次怎么做：**划出尾句提出的新概念、新变化或未解决的核心问题，按行文逻辑顺推下一步内容。

**禁止：**
- 选择上文已经详细论述过的重复内容
- 对策项未针对文段核心提出的具体问题（如欠薪问题核心在“证据不足”，对策必须针对证据不足）
- 脱离尾句重点发散至无关的宏观概念

### 片段阅读 · 语句填入

**固定识别：**根据横线所处位置（开头/中间/结尾）判断文段作用，结合上下文逻辑关系与句式特征选词句。

**考场步骤：**
- 看位置定作用：开头多总起概括；结尾多总结或对策；中间看前后是转折、承上启下还是对策/问题。
- 抓细节搭配：核对前后句主谓宾搭配、语法结构、逻辑关联词（如越……越……）及句式一致性。
- 核对指代与主语：确保全文主语一致，横线后指示代词能正确指代横线内容。

**知识要点：**
- 在开头：多为总起或概括句。
- 在中间：①前对策（若后文为论证描述）；②提出问题（若尾句为对策）；③承上启下（承与启皆为重点；若为转折句具有倾向性，看倾向前文还是后文，夸还是损）。
- 在结尾：多为总结句或对策句。

**下次怎么做：**观察横线位置并圈出前后紧邻的标点与关联词，判断填入句的承启方向。

**禁止：**
- 转折倾向性颠倒（夸损混淆）
- 关联词搭配不当
- 前后话题不一致（如把“不能接种”偷换为“拒绝接种”）
- 填入内容与后文解释说明脱节

### 片段阅读 · 语句排序

**固定识别：**借助选项组合，整体套入行文结构，细节抓首尾句特征与转折/指代/同词捆绑。

**考场步骤：**
- 看选项分布定首句：下定义、引出话题多为首句；指示代词开头、总结词开头一般不作首句。
- 细节找捆绑组合：通过关联词（转折/并列）、指示代词（如“这种观念意识”）、相同话题词锁定捆绑句对。
- 看尾句与结构验证：总结词（如“总之”）、对策句多为尾句；将锁定顺序代入验证行文结构（前/后对策、总分、并列）。

**知识要点：**
- 整体结构判定：前对策/后对策、总分、并列/大并列；注意转折/对比引出话题。
- 看首尾句规则：下定义多为首句；总结、对策多为尾句。
- 找组合规则：抓转折词、指代词、相同词锁定句群组合。

**下次怎么做：**对比四个选项的首句和两两绑定线索，先排两项后再代入整体结构通读。

**禁止：**
- 把含具体指代或转折的句子硬放在首句
- 拆散具有指代词和相同论述主题的捆绑句群
- 忽略尾句总结词的收尾作用

### 片段阅读 · 细节判断

**固定识别：**通过断句快速比对选项与原文，抓住致命问题排除干扰，允许正确项存在轻微瑕疵。

**考场步骤：**
- 阅读选项提炼关键信息点（主语、条件、逻辑、时态、程度词）。
- 回文定位断句，逐句核对选项与原文是否一致。
- 抓致命错误排除干扰项，对比择优。

**知识要点：**
- 解题特性：无需整体分析结构，只需断句比对；题与题相似性不大，需验证每个选项。
- 难题应对：逻辑性极强时深挖逻辑漏洞；正确项往往存在微小瑕疵，抓住其他选项的致命问题即可。
- 六大常见错误陷阱：偷换概念/语气/逻辑/数量、混淆时态、杂糅拼凑、本身有误（不符实际）、绝对化（过于绝对）、无中生有。

**下次怎么做：**根据选项核心名词回原文定位断句，逐字核对限定词与逻辑关系。

**禁止：**
- 无中生有（未提及对象）
- 过于绝对化表述
- 混淆概念关系（如将“减弱”说成“成正比”、“水底”扩充为“全流域”）

### 逻辑填空 · 词语辨析

**固定识别：**从语义拆分、程度轻重、感情色彩、词性态度及固定搭配多角度精准区分近义实词与成语。

**考场步骤：**
- 辨析语义：实词使用拆分法（拆单字）或组词法；成语记忆单一释义或对比近义差异。
- 辨析色彩与程度：核对词义程度轻重，判断感情色彩（褒义/贬义/中性）及作者态度（积极/消极/客观）。
- 核对搭配：检查常用词搭配与热点词搭配规范。

**知识要点：**
- 实词辨析方法：①拆分法（将词语拆分出单个字去理解）；②组词法（和其他词句搭配在一起理解）。
- 成语辨析：单一成语重在词义记忆，近义成语重在辨析差异。
- 其他维度：程度轻重；感情色彩（褒贬中性，积极/消极/客观）；固定搭配（主谓宾搭配、热点规范搭配）。

**下次怎么做：**遇近义实词先拆字组词，遇成语先辨析褒贬与轻重。

**禁止：**
- 只堆砌词义而不辨析侧重点与轻重
- 褒贬误用（在消极语境误选精美绝伦、美轮美奂等褒义词）

### 词语积累 · 易错成语（敬谦误用）

**固定识别：**辨清成语是用于自己的谦辞还是用于对方/他人的敬辞，杜绝敬谦错位。

**考场步骤：**
- 判断语境陈述主体是“自己/我方”还是“对方/他人/长辈”。
- 核对成语的敬谦属性。
- 敬辞不得用于自己，谦辞不得用于他人。

**知识要点：**
- 敬辞（用于对方/他人/长辈，不可用于自己）：鼎力相助（大力相助，只用于对方/他人）；不吝赐教（请教别人指教自己）；洗耳恭听（专心听别人讲话，不可用于要求别人听自己讲）。
- 谦辞（用于自己/我方，不可用于对方/他人）：蓬荜生辉（别人到自己家或题赠字画使自己光荣，不能用于别人）；抛砖引玉（用自己粗浅意见引出别人高明意见）；忝列门墙（自己有愧辱没他人）；诚惶诚恐（惶恐不安，用于自己）；敬谢不敏（推辞做某事的客套话）；敝帚自珍（自己珍视自己的东西）；不情之请（向人求助时称自己的请求）；绵薄之力（自己微薄的能力）。
- 特殊对象限定：不耻下问（向地位/学问比自己低的人请教，不可用于比自己高明或同等地位之人）。

**下次怎么做：**辨明横线所在分句的主语是“我/我们”还是“您/对方”，严格匹配敬谦辞。

**禁止：**
- 将“鼎力相助”用于表达自己帮助别人
- 将“抛砖引玉”“蓬荜生辉”“敝帚自珍”用于对方或他人
- 向领导、专家请教时使用“不耻下问”
- 要求别人听自己讲话时使用“洗耳恭听”

### 词语积累 · 易错成语（特定对象）

**固定识别：**严格核对成语所限定的陈述主体、对象范围及修饰搭配，杜绝对象张冠李戴。

**考场步骤：**
- 圈出文段中成语所修饰或陈述的中心主体（夫妻、长辈晚辈、书籍、房屋、特定感官等）。
- 检索成语特定陈述对象限制。
- 排除陈述对象不符及搭配不当的选项。

**知识要点：**
- 夫妻关系专属：破镜重圆（夫妻团圆，不用于兄弟）；相敬如宾；比翼齐飞；举案齐眉（夫妻互敬互爱）；劳燕分飞（多用于夫妻别离）。
- 长幼/上下级专属：耳提面命（长辈对晚辈、上级对下级、师长对弟子，不用于朋友）。
- 书籍专属：汗牛充栋（形容书籍多，不形容人或其它事物；注意区分学富五车）。
- 建筑装饰专属：美轮美奂（适用于新屋高大美观或装饰布置美好）。
- 特定感官与状态：司空见惯（只能是“见”，不能是“听”）；如数家珍（适用于本来不是自己家珍的事物）；萍水相逢（向来不识之人偶然相遇，不用于熟人）。
- 人品与事物区分：良莠不齐（指好人坏人混杂，侧重品质，适用于人，不用于成绩、物件）；洗心革面（犯错误的人彻底悔改；区分脱胎换骨）；七手八脚（人多手杂做状语；区分手忙脚乱）。
- 极品与罪恶：叹为观止（精妙完美之极的美好事物，不用于一般事物或贬义）；罄竹难书（坏事和罪恶多，不能形容好人好事）；一言九鼎（说话分量重，不表示守信用，不用于自己）。
- 搭配禁忌：苦口婆心不能跟“一番”搭配（区分语重心长、苦心孤诣）；望其项背对象只能是人且多用于否定。

**下次怎么做：**锁定成语修饰的名词性质，核对是否符合夫妻、长辈、书籍、建筑等特定对象限制。

**禁止：**
- 用“破镜重圆”“举案齐眉”形容朋友或兄弟
- 用“美轮美奂”形容文章、歌声或普通非建筑装饰事物
- 用“良莠不齐”形容学生成绩、产品质量
- 用“苦口婆心”与“一番”搭配

### 意图判断

**固定识别：**「意在说明」「旨在」「想要表达」。广东 2026 有 3 道，比主旨更常见。

**考场步骤：**
- 先当主旨做一遍（主题词 + 重点句）。
- 有问题/教训 → 优先对策，但对策必须能对上该问题。
- 纯介绍/评价、没有可解的问题 → 选主旨同义，禁止硬加「我们应该」。
- 精神提炼选能概括该精神的项，不选更空的口号。

**知识要点：**
- 主旨问「这段说了什么」；意图问「写这段要你明白什么」。
- 排除：复述例子、过度引申、对策错配。

**下次怎么做：**先抽出问题；有问题选能对上的对策，没问题选主旨。

### 尾句推断

**固定识别：**「作者接下来最可能讲的是」。广东少见；你指定过方法，必须遵守。

**考场步骤：**
- 不看全文中心。只看横线前一句的最后一个关键词。
- 选项必须贴紧该词继续说，换话题立刻删（即使那是全文主旨）。
- 已论述完的不重复，反对前文的不选。

**知识要点：**
- 国考多、广东少。一旦出现仍按此做。

**下次怎么做：**眼睛只钉前句尾词，选项换词就滚。
