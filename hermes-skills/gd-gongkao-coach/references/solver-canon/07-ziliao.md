# 资料分析 · 解题口径（广东省考）

> 本文件按资料分析 PDF 重构。固定执行“定型 → 找数 → 列式 → 速算”，重点检查时间、单位和分母。

## 固定动作

1. 先看设问，确定模块和题型。
2. 输出固定知识点标签：`本题考察知识点：模块-一级知识点-二级知识点`。
3. 按对应卡片的步骤写进 `#### 考场解法`；每个干扰项点名陷阱。排版走 `practice-review-spec.md`：对错分流，`#### 下次动作` 必须 `触发：… → 优先：…`。禁止把「下次怎么做」收成没有标题的一句。
4. PDF 未覆盖的新变体，先套最接近的母题型；确认有独立定义和动作后，按 `knowledge-point-extension.md` 补录。

广东资料分析通常为 4 篇材料 × 5 题。每道题解析先标出现期/基期、增长量/增长率、比重/平均数等一级题型，再写对应公式。

复盘排版：先放整篇 `### 材料一` + `> **材料**`，再连续讲该篇 5 题；讲完再放下一篇材料。每题 `原题` 只放问句和选项，不要把整篇材料复制五遍。单题标题按 `practice-review-spec.md` 对错分流，最后 `### 本场结语`。

## 题型卡片

### 基础知识 · 统计术语与常考概念

**固定识别：**考查核心统计概念辨析及做题原则，先看时间点（基期/现期）、单位及主语对应关系。

**考场步骤：**
- 分析问题确定求基期还是现期，抓取核心关键字。
- 略读数据，圈出数据前修饰词并优先核对特殊单位（如千分数‰）。
- 依据术语定义或公式列式。

**知识要点：**
- 倍数＝增长率＋1；翻n番为原来的2^n倍。
- 一成相当于总量的10%，几成相当于百分之几十。
- 同比与历史同期比；环比包含日/周/月/年环比。
- 顺差：出口＞进口；逆差：出口＜进口。
- 国内生产总值(GDP)＝第一产业增加值＋第二产业增加值＋第三产业增加值。
- 人口自然增长率＝人口出生率－人口死亡率（单位‰）。
- 新中国成立初指1949年后几年；改革开放指1978年至今；十五计划时期为2001-2005年；十四五为2021-2025年（4×5+1=21起算）。
- 恩格尔系数：食品支出占消费总支出比重，越低生活水平越高（0~1）；基尼系数：衡量收入差距，越小差距越小（0~1）。
- 饼状图画图规律：从12点钟方向顺时针分布，关注25%、50%等特殊比例。

**下次怎么做：**审题时圈出时间、关键词与单位，避免混淆增加值与增长量。

**禁止：**
- 把增加值当作增长量
- 进口＋出口＝进出口混淆
- 人口自然增长率遗漏千分号‰

### 速算技巧 · 加法与减法

**固定识别：**考查多位数加减计算，先看选项末位或差距特征决定采用尾数还是分段截位。

**考场步骤：**
- 观察选项末位：末几位不同就用尾数法算几位（减法不够减往前借位）。
- 多位求和时用高位叠加法，从高位加起，不足两位在前添0。
- 求一组接近数据的平均数时选基准值，用削峰填谷法口诀计算。
- 两位数相减使用划线减法（12分段或21分段）拆分心算。

**知识要点：**
- 削峰填谷法：平均数＝基准值＋(偏离总和 / 项数)。
- 基准值法：被减数－减数＝(被减数－基准值)＋(基准值－减数)。
- 划线减法：12分段法（如 7|64－5|39＝2|25）；21分段法（如 72|9－53|4＝19|5）。

**下次怎么做：**加减运算先看选项差异，多项求和用高位叠加，求均值用削峰填谷。

**禁止：**
- 尾数相减不够减忘记向前借位
- 高位叠加法十位等不足两位漏添0导致错位

### 速算技巧 · 乘除截位与分数比较

**固定识别：**考查乘除法快速估算与分数大小判定，先看选项差距大小确定截位位数与方法。

**考场步骤：**
- 乘法估算：截2位看第3位（≤2全舍，≥8全进，其余一进一舍），或拆成常见百分数相加减。
- 除法截位：一步除法只截分母；多步乘除同截分子分母。
- 判定除法截几位：选项首位不同或首位相同次位差大于首位（差距大）截2位；首位相同次位差≤首位（差距小）截3位。
- 分数比较：同大同小纵向直除或横向看倍数；一大一小直接看（分子大则分数大）。

**知识要点：**
- 小分互换：百分数与分母互换位置（如 1/13≈7.7% <=> 1/7.7≈13%）。
- 常用百分数：1/2=50%、1/3≈33.3%、1/4=25%、1/5=20%、1/6≈16.7%、1/7≈14.3%、2/7≈28.6%、3/7≈42.9%、1/8=12.5%、1/9≈11.1%、1/11≈9.1%、1/12≈8.3%。
- 除法拆分：分子拆为基准百分比与调整项加减（如 332/688 = (344-12)/688 = 50%-2%^-）。

**下次怎么做：**一步除法只截分母，根据选项首位和次位差距决定截2位或截3位。

**禁止：**
- 选项存在10^n倍量级差异时截位后遗漏量级判断

### 速算技巧 · 415份数法与假设分配法

**固定识别：**考查已知现期量与增长率快速拆解基期量与增长量，先看增长率是否接近常见分数。

**考场步骤：**
- 415份数法：将R化成相近分数a/b；按 基期:变化量:本期量＝b:a:(a+b) 对应份数求一份量，再算X与A。
- 增长率为负时化为 4(-1)3 份数法，基期使用 A＝B－X 控制误差。
- 假设分配法：确定被分配数B和R，画分配树抓大放小拆分大数。
- 分配树最后一步按R大小修正：R<20%直接X≈BR；25%左右A:X=4:1；33%左右A:X=3:1；50%左右A:X=2:1；66%左右A:X=3:2；80%以上平分再修正。

**知识要点：**
- 常见百分数对应分数表：1/2=50% 至 1/19≈5.3%。
- 份数比例：基期:变化量:本期量＝b:a:(a+b)。
- 分配树公式：X1＝A1×R，A1＋X1＝B，X2＝A2×R，最终 A＝A1＋A2，X＝X1＋X2。

**下次怎么做：**增长率靠近分数用415份数法，R较小或难化简分数用假设分配法抓大放小。

**禁止：**
- 负增长时份数比例正负号弄反（应为b:-a:(b-a)）

### ABRX类 · 基期量计算与比较

**固定识别：**考查基期量相关求解，先看是直接求基期、求隔年前期还是求基期差值。

**考场步骤：**
- 直接求基期：识别题目中的现期B和增长率R，代入公式 A＝B/(1+R) 或 A＝B－X 计算。
- 求隔年前期：先求间隔增长率 R间＝R1＋R2＋R1×R2，再套基期公式或假设分配法求基期。
- 求前期差值：分别求出 A1 与 A2 之后作差。

**知识要点：**
- 核心公式：A ＝ B / (1+R) ＝ B － X ＝ X / R。
- 隔年增长率：R间 ＝ R1 ＋ R2 ＋ R1×R2。

**下次怎么做：**看到隔年前期，第一步先算 R间＝R1＋R2＋R1R2，再由现期求基期。

**禁止：**
- 求隔年基期时直接用两期增长率简单相加

### ABRX类 · 增长率计算模型

**固定识别：**考查一般增长率、间隔增长率、比值增长率或乘积增长率，先看题目逻辑关系属于加减、乘积还是比值。

**考场步骤：**
- 一般增长率：由增量与基期直接求 R＝X/A。
- 间隔增长率：两期增速已知时代入 R间＝R1＋R2＋R1×R2；若已知R间和R2求R1，则逆用公式 R1＝(R间－R2)/(1＋R2)（速算用 R1＝R间－R2－R1R2 定界）。
- 比值增长率：满足 A＝B/C（如人均、单价、均前每后做分母），代入 Ra＝(Rb－Rc)/(1＋Rc)。若求比值倍数则为 比值增长率＋1。
- 乘积增长率：满足 A＝B×C（有实际含义或表示整体×占比），代入 Ra＝Rb＋Rc＋Rb×Rc。

**知识要点：**
- 比值增长率口诀：“均前每后做分母”，若未给比值本身数据而给分子分母增速，直接套 (Rb－Rc)/(1＋Rc)。
- 乘积增长率公式：Ra ＝ Rb ＋ Rc ＋ Rb×Rc。

**下次怎么做：**判断指标关系是乘积还是比值：乘积用相加加乘积，比值用做差除以(1+分母增速)。

**禁止：**
- 比值增长率公式中分母误用分子增长率（牢记均前每后做分母）

**PDF锚点：**PDF p7-p8：ABRX类

**主标签：**`资料分析-ABRX类-增长率计算模型`

### ABRX类 · 增长量计算与现期推算

**固定识别：**考查增长量大小计算或基于增量/增速推算未来现期，先看增长率大小决定计算策略。

**考场步骤：**
- 直接求增长量：若 R≥10% 且靠近分数用 415 份数法；若 R<10% 用假设分配法；若 R≤5% 极小直接 X≈BR；选项差距极小时用直除或代入法。
- 假设增量求现期：设n年后达标，列不等式 当年量＋n×增量x ＞ 目标值（年均增量年份算到秒，(末年－首年前一年)/n）。
- 假设增速求现期：B＝A＋AR，逐年递推2~3次求得。

**知识要点：**
- 核心公式：X ＝ B － A ＝ AR ＝ B/(1+R) × R。
- 未来达标不等式：基期/当年量 ＋ n × 增量 ＞ 目标量。

**下次怎么做：**根据增长率大小选用415份数法或X≈BR估算增长量。

**禁止：**
- 年均增量算跨年年份差时漏算前一年（2011-2016年应为(2016-2010)/6）

### 比重类 · 现期、基期与隔级比重

**固定识别：**考查比重基础计算、多部分合成比重及隔级比重，先看是当期还是前期或跨层级。

**考场步骤：**
- 本期比重：直接套用 部分 / 整体。
- 多部分比重：求和或求差后代入 部分和(差) / 整体。
- 基期比重：寻找现期比重及部分、整体增速，代入 基期比重＝现期比重 × (1＋R整体) / (1＋R部分)。
- 隔级比重：寻找中间过渡量，通过 小/大 ＝ (小/中) × (中/大) 或 (小/中) ÷ (大/中) 计算。

**知识要点：**
- 基期比重公式：(A/B) × (1＋Rb)/(1＋Ra) ＝ 现期比重 × (1＋R整体)/(1＋R部分)。
- 隔级比重本质：通过中间层级比重乘除实现跨级过渡。

**下次怎么做：**算基期比重先列出 现期比重×(1+R整体)/(1+R部分)，再截位计算。

**禁止：**
- 基期比重公式中部分增速与整体增速位置颠倒

**主标签：**`资料分析-比重类-现期、基期与隔级比重`

### 比重类 · 比重趋势、比重差与比值差

**固定识别：**考查比重升降判断及差值计算，先比分子分母增速，再看差值范围与公式。

**考场步骤：**
- 比重趋势判断：R部分 ＞ R整体 则比重上升；R部分 ＜ R整体 则比重下降（逆运用：比重变大说明分子增速快）。
- 比重差解题三步法：①由 R部分－R整体 符号判断升降排除两项；②利用 |比重差| ＜ |R部分－R整体| 秒杀排除选项；③若需精算，套用公式 (基期部分a / 本期整体B) × (R部分－R整体)，用假设分配粗算a代入。
- 比值差计算：问法为平均数/比值与上年相比差多少（带实际单位），套公式 (基期部分a / 本期整体B) × (Ra－Rb)，不可用小于增速差秒杀。

**知识要点：**
- 比重差公式：比重差 ＝ (基期部分a / 本期整体B) × (R部分 － R整体)。
- 比重差秒杀技：|比重差| ＜ |增长率之差|（前提是基期部分/本期整体 < 1）。
- 比值差公式：(去年出口额a / 今年出口量B) × (R额 － R量) ＝ a/B × (Ra － Rb)。

**下次怎么做：**做比重差题先看趋势正负，再看差值是否小于增速差，绝大多数直接秒杀。

**禁止：**
- 比值差（带实际单位）盲目套用|差值|<|增速差|秒杀

**主标签：**`资料分析-比重类-比重趋势、比重差与比值差`

### 盐水类 · 十字交叉法与混合增长率

**固定识别：**考查存在部分加和为整体的混合比率或平均数，先画十字交叉找分母之比。

**考场步骤：**
- 验证前提：三量间存在加和关系（如 整体＝部分1＋部分2；累计月＝前N月＋当月）。
- 定性定界：混合值居中，偏向基期/分母量大的一方（部分1 ＞ 整体 ＞ 部分2）。
- 定量十字交叉：两端放部分率，中间放混合率，交叉做差，得出对应分母之比。
- 若代入的是增长率R，求出的是基期量A之比；若代入的是人均量，求出的是总人数之比。

**知识要点：**
- 十字交叉模型：(R1 － R混) / (R混 － R2) ＝ 分母量2 / 分母量1。
- 时间分段关系：R(12月) 与 R(1-11月) 混合得到 R(1-12月累计)。

**下次怎么做：**确认加和关系后画十字交叉，记住交叉差值比等于基期量或分母之比。

**禁止：**
- 十字交叉算出的比例误当成现期量之比（算出来的是基期量A或分母之比）

### 比较类 · 双线法与增量比较

**固定识别：**考查多个主体增速或增量的大小排序，先看现期B与增长率R的倍数关系。

**考场步骤：**
- 双线法比较增速：分子增量X变小、分母基期A变大，则整体分数值(增速)必然变小。
- 增量比较原则（R>0）：①大大则大（现期B大且R大，增量X必大）；②一大一小看倍数（现期B是n倍，R需在n倍以上增量才可能相等）。
- 增长率超10%快速判断：看是否满足 A ＋ 0.1A ＜ B 或 (B－A)/A ＞ 10%。
- 图表查找比对：核对起止年份月份、避开“合计/总计”干扰行、关注第一年增量与单位。

**知识要点：**
- 增量比较口诀：大大则大，一大一小看倍数。
- 增量公式推导：X ＝ B × [1 － 1/(1+R)] ＝ B/(1+R) × R。

**下次怎么做：**比较增量大小时先找B和R都大的主体秒杀，一大一小时横向比倍数。

**禁止：**
- 图表查找时错把“合计”当成具体项目
- 增量比较口诀误用于负增长（R<0）

**PDF锚点：**PDF p12：比较类

**主标签：**`资料分析-比较类-双线法与增量比较`

### 平均类 · 一般平均值与年均增速/增量

**固定识别：**考查现期/平均指标、年均增量及年均增速，先看时间跨度、分母位置与基期年判定。

**考场步骤：**
- 一般平均值：口诀“均前每后做分母”，求“每100/每万”只需算出有效数字再看量级；涉及多除法时化为 (A/B)÷(C/D)＝AD/BC 先约分。
- 年均增长量计算：公式为 (末期－基期)/年份差n。若图表能直接找到前一年且推算有答案则推前一年（严谨：2020-2022年为(2022-2019)/3；不严谨为(2022-2020)/2）。
- 年均增长率计算：套用 (1＋R)^n ＝ 末期/基期；若选项极小或极不正常时用近似公式 末期/基期 ≈ 1＋nR。

**知识要点：**
- 常用乘方常数：1.05^4 ＝ 1.216，1.10^4 ＝ 1.46，1.15^4 ＝ 1.75，1.20^4 ＝ 2.07。
- 闰年判定规则：能被400整除，或能被4整除但不能被100整除（闰年2月有29天）。

**下次怎么做：**算年均增长量先看图表是否包含起始前一年以确定基期与n。

**禁止：**
- 年均增长量基期年份判定错误
- 平年闰年天数算错

### 特殊考点 · 拉动增长、贡献率与容斥

**固定识别：**考查拉动增长率、增量贡献率及集合交集范围，先分清分母是整体基期还是整体增量。

**考场步骤：**
- 拉动增长率：找准部分增量与整体基期，代入 拉动增长率＝部分增量 / 整体基期。
- 增量贡献率：找准部分增量与整体增量，代入 增量贡献率＝部分增量 / 整体增量。
- 容斥问题分析：①占比和＞100%则一定有交集；②问“至多”用大比重包含小比重；③问“至少”用 相斥公式 计算。

**知识要点：**
- 拉动增长率 ＝ 部分增量 / 整体基期。
- 增量贡献率 ＝ 部分增量 / 整体增量（整体增量＝B－A）。
- 两集合容斥至少公式：至少 ＝ a ＋ b － 100%（或 a ＋ b － 总量）。

**下次怎么做：**看到“拉动”分母找整体基期，看到“贡献率”分母找整体增量。

**禁止：**
- 将拉动增长率分母（整体基期）与增量贡献率分母（整体增量）搞混
