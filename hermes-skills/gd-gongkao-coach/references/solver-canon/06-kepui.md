# 科学推理 · 解题口径（广东省考）

> 广东独有。2024 起独立大标题，**5 题**（不要按旧的 10–11 题投入时间）。
> 2026 实测：力学 1、压强浮力 1、电学 1、地理 1、生物 1（化学 0）。物理仍过半，大量带图。
> 大纲程度接近初中理科 + 少量高中。用模型，不背奥赛。

公式 Unicode。带图题讲「先读哪根线」；无图不出立体电路。

---

## 共用四步

1. **定学科**：力 / 浮力压强 / 电 / 光热 / 化 / 生 / 地理。
2. **定问法**：比较大小、方向、变化趋势、选原理、读图。
3. **先定性再定量**：增还是减、向上还是向下，很多题不用算到数。
4. **单位与控制变量**：只改题干改的那个量，其余当不变。

**禁止：**用生活感觉对抗定律（「重的先落地」对抗自由落体）。定律优先。

---

## 一、力学

**高频：**受力分析、惯性、摩擦力方向、牛顿定律、杠杆滑轮、平抛、v-t / F-t 图像、功和功率。

### 步骤

1. 隔离物体，画力：重力、弹力、摩擦、拉力。有图先把力画全。
2. 平衡：合力为 0，杠杆 F1 L1 = F2 L2。
3. 运动：F=ma 只在需要加速度时上；惯性解释「突然刹车人往前」。
4. 图像：v-t 斜率是加速度，面积是位移；读清坐标轴。
5. 平抛：水平匀速、竖直自由落体，时间由高度决定。

**下次怎么做：**先画力，再谈运动。

---

## 二、压强与浮力

**高频：**p=F/S，液体 p=ρgh，阿基米德 F浮=ρ液 g V排，浮沉，容器底部受力。

### 步骤

1. 固体压强看压力和受力面积（是否竖直作用在面上）。
2. 液体压强只看深度和密度，与容器形状无关（帕斯卡/连通器要分清问的是压强还是压力）。
3. 浮力：看排开液体的体积，不是物体体积（没浸没就不是全部）。
4. 浮沉：ρ物 vs ρ液。漂浮 F浮=G。
5. 容器底部压力 = 液体重力 + 可能的额外压力，形状不规则时「压力 ≠ p×底面积」的例外要小心——以题干模型为准。

**下次怎么做：**先问「这是固体压强还是液体压强」，浮力先写 V排。

---

## 三、电学

**高频：**串并联、欧姆定律、电功率、开关多档、热敏电阻、动态电路。

### 步骤

1. 开关闭合后，哪些电阻被短路、哪些被接入。**先改电路再算。**
2. 串联：电流相等，电压分成，R=R1+R2。
3. 并联：电压相等，电流分成，1/R=1/R1+1/R2。
4. 功率：已知选公式 P=UI = I²R = U²/R。电源电压不变时，并联越多总功率越大。
5. 多档位：看挡位改变的是串联还是并联支路。
6. 热敏/光敏：阻值随温度/光照变，当作可变 R 再走欧姆。

**下次怎么做：**短路/断路判断完再动公式。

---

## 四、热学 / 光学（近年少，备用）

- 热：熔化凝固温度、比热容（吸收热量 Q=cmΔt）、热胀冷缩、海陆热力差异（陆地比热小，升温快）。
- 光：直线传播、反射定律、折射（从空气进水向法线偏）、透镜（凸透镜会聚）。
- 结构色 vs 色素色：结构色随角度变。

---

## 五、化学

**步骤：**

1. 反应类型：化合 / 分解 / 置换 / 复分解。
2. 守恒：原子种类个数、质量。
3. 溶液：饱和、降温结晶、气体溶解度降温升压才升高。
4. pH：<7 酸 >7 碱；中和。
5. 金属活动性顺序：前面的能置换后面的。
6. 燃烧三要素；不完全燃烧出炭黑（蜡烛）。

**下次怎么做：**先配平或先定性（酸还是碱、气还是固），再谈现象。

---

## 六、生物

**高频：**光合呼吸、细胞、遗传、食物网与营养级、免疫与传染病、血糖与胰岛素、细菌。

### 步骤

1. 食物网：箭头指向捕食者；数营养级从生产者开始。
2. 能量单向递减，约 10%–20%。
3. 光合需要光、吸收 CO₂ 释放 O₂；呼吸相反。
4. 胰岛素降血糖；缺了会怎样题干会给症状。
5. 细菌：有的有益有的致病，不要「细菌=有害」。

**下次怎么做：**先画食物网箭头，再数级。

---

## 七、地理

**高频：**锋面雨、气团抬升、海陆风、等高线、选址。

### 步骤

1. 等高线：密=陡；闭合中高周低=山峰；河谷等高线凸向高处。
2. 冷暖锋：冷气团主动=冷锋，降水在锋后为主；暖气团主动=暖锋，降水在锋前。交汇抬升致雨。
3. 海陆风：白天吹海风（陆地升温快气压低），夜晚相反。
4. 选址：水库、避灾、向阳坡，用等高线+风向+水源同时约束。

**下次怎么做：**先读图例和等高距，再谈天气或选址。

---

## 八、考场策略（只有 5 题）

- 带图题：图没读完不动选项。
- 计算量大于初中作业的：先看选项数量级和单调性。
- 放弃标准：完全没有模型的化学方程式细节题，别拖资料的时间。
- 成套出题：日常判断 20 题的最后 5 题即本模块。5 题学科按近年真题均衡——力学、压强浮力、电学、生物、地理（物理过半，生物、地理各 1；化学可轮空，光学/热学近年少见）。不要 5 题同一科。

## 解析知识点固定词表（每题必选一个主标签）

解析、PDF 复盘、AI 出题统一使用 `科学推理-一级-二级`；带图题也必须先标物理/化学/生物/地理分支。

| 一级知识点 | 二级知识点 |
|---|---|
| 力学 | 受力平衡、摩擦与惯性、杠杆滑轮、运动图像、平抛运动 |
| 压强与浮力 | 固体压强、液体压强、阿基米德原理、浮沉条件、容器底部受力 |
| 电学 | 串并联、电路故障、欧姆定律、电功率、档位开关与热敏电阻 |
| 热学与光学 | 热传递与内能、比热容、反射折射、透镜成像、声学 |
| 化学 | 质量守恒、反应类型、酸碱与 pH、金属活动性、生活化学 |
| 生物 | 人体调节、遗传、生物技术、食物网、生态系统与能量 |
| 地理 | 等高线、锋面天气、海陆风、季风洋流、区域地理 |

不要用“科学常识”作为主标签；主标签必须能指向下一次具体复习动作。
