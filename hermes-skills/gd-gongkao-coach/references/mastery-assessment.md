# 掌握与熟练度评估口径 v2

本口径适用于 AI 练题与录屏/真题复盘。题目质量沿用已有流程，不额外审核。
掌握等级由脚本计算；Hermes 负责解释逐题证据，不能手填掌握分或为了升级补造证据。
原始对错、时间与过程判断分开。缺少过程证据不能推断不会，也不抹掉历史表现。

## 历史继承

系统从已记录题目的原始练习判分和录屏/真题作答记录，提取最近10道可追溯首次作答。至少3题时，正确率低于50%暂列历史薄弱，50%至不足80%列历史待巩固，80%以上列历史表现较好；不足3题显示已有作答。这些是暂定历史判断，不是独立性或稳定掌握认证。记录用时可展示，无考试预算时不能认证熟练。

有历史事件但无法核对题目/结果时显示已有学习记录，保留学习经历；聊天记忆可指向当时原题、独立作答或报告，再通过 --assess 补证据，不能把“讲过/模型说会了”直接换算掌握。优先补即将推荐的常考点和近期练习，不要求重新分析全部旧卷。新口径已有过程判断时优先使用，并同时展示历史依据。每个原题只作一次首次作答基线，有提示的记录不加入；同题重做只反映纠错进展。

## 写入流程

1. 按报告记录客观对错与用时：AI 练题用 `--record ... practice --practice-id 场次 --item 题目id`；录屏/真题用 `--record ... exam --exam-id 场次 --item 题号`。已记录则跳过新增。空题自动证据不重复写；秒过未记录的空题也不补造。
2. 每道已记录题，包括答对、答错、重做与自动记录的空题，都按本口径调用 `--assess`。过程无法判断也明确写 unknown。已封存场次允许补充或修正评估，不增加作答数；修订保留历史。
3. 全部应记录题完成记录与评估后，调用 `--seal-practice 场次` 封存。评估写入失败不得宣称已完成。不得用 `--force` 绕过缺失证据。
4. 簿记静默执行，不在复盘正文主动报告分数或命令。标签沿用已登记词表。

```bash
python3 /home/ubuntu/ExamSystem/scripts/kaodian_profile.py --assess practice 123 456 '{"independence":"independent","process":"correct","basis":"draft","execution":"hesitant","reason":"草稿先列不相邻模型，关键关系正确，末步约分出错；作答前未看提示。","template":"不相邻-插空","variant":false,"mixed":false,"timing_valid":true,"target_seconds":90,"target_basis":"示例：用户已确认该难度考法在考试中的预算为90秒"}'
```

上面仅为格式示例，场次、题目、判断、目标时间必须替换成真实依据，不得照抄90秒。

## 字段判断

- `independence`: `independent` / `assisted` / `unknown`。以可确认的作答条件、用户说明或录屏为依据。有提示、看过解法后重述为 assisted；无法确认则 unknown。原题重做由系统排除，不因独立重做就算新题。
- `process`: `correct` / `partial` / `incorrect` / `unknown`。识别、建模与关键推理正确，末步计算失误可以 correct；关键链条不全为 partial；模型错误为 incorrect；草稿缺失且没有独立解题说明为 unknown。答对不自动等于过程正确，草稿少也不自动判错。
- `basis`: `draft` / `explanation` / `unavailable`。explanation 只接受未看讲解前独立给出的解题说明；复盘后模仿标准解法不是原始证据。
- `execution`: `smooth` / `hesitant` / `unknown`。仅根据草稿步骤、回退与独立解题行为判断，不能仅凭快慢推断。
- `reason`: 必填，引用本题关键一步及判断依据；不明时写缺什么。不要写空泛的“基本掌握”。
- `template`: 使用稳定的考法/结构名称。同一天同模板只保留首次有效检验；不填时同考点当天合并为一次。不能为了多计样本给相同结构另起名字。这是证据分组，不是新知识点标签。
- `variant`: 布尔值，仅已确认相对先前训练存在结构迁移时为 true；换数字、换场景而模型动作相同不能算结构变式。
- `mixed`: 布尔值，只有混合练习中未预告具体考法、需要自己识别时为 true。
- `timing_valid`: 布尔值，已确认没有暂停、离开或中途讲解时才为 true；不清楚用 false。
- `target_seconds` / `target_basis`: 可省略。依据同考法、同难度的考试预算、用户确认目标或可核查的成熟基准。不得按本次耗时倒推目标，不得每题套统一秒数，不得事后放宽目标来达标。target_basis 明确来源；无基准就不判速度等级。

## 自动等级

- 原题跨场重做排除；同日同模板只取首次有效检验；有提示、独立性不明、过程不明不用于认证等级。保留原始记录。
- 最近5次独立检验中至少4次关键过程正确，跨至少2天，且存在成功的结构变式：已掌握。
- 达到已掌握后至少间隔7整天，新题独立检验成功，并且最近窗口包含成功的混合练习识别：稳定掌握。
- 尚未达标但已有完整独立过程：初步掌握；最近3次中至少2次关键过程错误：尚未掌握；其余证据不足：待评估。
- 新失败导致最近窗口不满足条件时会降级；超过30天没有有效检验保留历史等级并标“待复测”，不把缺练当成已遗忘，也不把旧等级当成当前认证。
- 熟练度只取最近5次有效检验中答案与过程均正确、有效计时、有目标及执行依据的题。至少3题跨2天才评级。80%以上达时且80%以上过程顺畅为熟练；60%以上达时为达标；否则需提速。证据不足或超过30天未测为待评估。
- 阈值是透明的起始业务标准，不是统计置信概率。旧 Beta 分只供兼容练习排序，不能说成真实掌握率；知识债清偿与稳定掌握不是一回事。
- 新练习创建时保存作答前等级；之后累计已掌握/稳定掌握的新题检验对错，供验证评级是否高估。样本少时不能宣称经过科学校准。

历史数据缺少当时草稿、独立性或时间基准时，不追认、不虚构；等待后续独立证据。评估的“待评估”不表示学员不会。
