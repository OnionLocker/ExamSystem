# 广东省考历年考试时间（联网查询记录）

## 来源
2026-06-15 通过 `curl -sL "https://m.baidu.com/s?word=广东省考时间安排"` 查询到的百度移动版结果。

## 关键发现
2026年度的广东省考采用**年底模式**：
- **报名时间**：2025年10月20日 9:00 至 10月24日 16:00
- **笔试时间**：**2025年12月7日（星期日）**
  - 《行政职业能力测验》：14:00-15:30（90分钟/90题）
  - 《申论》：16:15-18:45（150分钟）
- **成绩查询**：2026年1月15日

## 完整历史时间线

| 年度 | 公告时间 | 报名时间 | 笔试时间 | 模式 |
|------|---------|---------|---------|------|
| 2026年度 | 2025年10月 | 2025.10.20-10.24 | **2025.12.7** | 年底模式 |
| 2025年度 | 2025年1月 | 2025.1.8-1.14 | **2025.3.15** | 年初模式 |
| 2024年度 | 2024年1月 | 2024.1.16-1.22 | **2024.3.16** | 年初模式 |
| 2023年度 | 2023年1月 | 2023.1.10-1.16 | **2023.2.25** | 年初模式 |
| 2022年度 | 2021年11月 | 2021.11.29-12.3 | **2022.1.3** | 跨年模式 |

## 对2027年度的预测
广东的时间模式一直在变，无法预判下一场是延续2026年度的年底模式（2026年10月公告→12月笔试），还是回归年初模式（2027年1月公告→3月笔试）。**需要询问用户他准备的是哪一场。**

## 有效搜索方法（本机已验证）
```bash
# ✅ 可用的搜索方式
curl -sL --connect-timeout 5 --max-time 10 \
  "https://m.baidu.com/s?word=<URL编码的中文关键词>" \
  -H "User-Agent: Mozilla/5.0 (Linux; Android 10; K) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Mobile Safari/537.36"
# 输出后需要去掉<script>和<style>标签再提取文本

# ❌ 不可用的搜索方式
# - www.baidu.com/s? -> 触发安全验证码
# - www.google.com -> 超时被墙
# - www.bing.com -> 超时
# - cn.bing.com -> 超时
# - weixin.sogou.com -> 能通但返回压缩JS无搜索结果

# ⚠️ 代理可用（hysteria2 socks5://127.0.0.1:1080）但curl走代理访问外网效果不稳定
# requests库缺PySocks无法走代理
```
