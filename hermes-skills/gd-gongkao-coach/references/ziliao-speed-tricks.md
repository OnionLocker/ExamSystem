# 资料分析 · 考场速算决策手册

> 复盘、讲题写 `#### 考场解法` 时按本文件选算法。核心：**先看选项定精度，再按题型选最省的技巧；直除是保底，不是默认。**
> 用户画像：排斥通篇截三位直除，习惯基准数拆分（1＋余数）和同乘凑整。用户的拆分/凑整只要误差够用就认可，在他的写法上压缩，不强改成直除。

## 一、第一步永远是看选项：误差预算

1. **算选项最小相对差距 d**：相邻两个选项之差 ÷ 较小值。例：2.08 与 2.17 → d≈4%；12366 与 12902 → d≈4%；6.4% 与 6.6% → d≈3%。
2. **估算误差必须小于 d 的一半**，该估算才可用。常用近似的误差：

| 近似动作 | 相对误差 | 能用的场景 |
| :--- | :--- | :--- |
| 分母截 2 位 | 最多约 5% | d ≥ 10% |
| 分母截 3 位 | 最多约 0.5% | 几乎都够 |
| B/(1+r) ≈ B×(1−r) | ≈ r²（r=5% 时 0.25%，r=10% 时 1%） | \|r\| ≤ 10% 求基期 |
| 增长量 ≈ B×r（漏掉 1+r） | ≈ r（r=4.5% 就差 4.5%） | 仅 d 明显大于 r 时 |
| 增长量 ≈ B×r×(1−r) | ≈ r² | \|r\| ≤ 10% 求增长量 |
| 百化分 r≈1/n | 约等于 r 与 1/n 的相对差 | 差得小于 d/2 时；否则按偏大/偏小修正 |
| 年均增速 1+nr | r 越大越高估（5 年 16.7% 会高估到 23%） | 仅 r 很小（≤5%）或选项差距很大 |

3. **精度分三档**：
   - d ≥ 10%：首位、量级、方向就能选，截 2 位；
   - 3% ≤ d < 10%：百化分、拆分、同乘凑整、近似公式，一般 1～2 行出数；
   - d < 3% 或技巧结果正好落在两个选项中间：只在两个候选里**估商代入**（选项×分母，与分子比），或截 3 位直除到第 3 位。这时直除最稳，无可厚非。

## 二、不算就能排除的选项（先做）

- **方向**：基期 < 现期（正增长）；增长量 < B×r；|比重差| < |a−b|；平均数增速 (a−b)/(1+b) 在 b>0 时略小于 a−b；混合增速介于两部分之间、偏向基期大的一方。
- **量级**：万/亿、%/百分点、千瓦时/万千瓦时，先定量级再算有效数字。
- **陷阱值识别**：命题人常把错误算法的结果放进选项。
  - 两个选项之比约等于 (1+r) → 大的那个是“漏除 1+r”的陷阱（如增长量 2.17 vs 2.08，2.17/2.08≈1.045）；
  - 平均数增速选项里出现 a−b 本身 → 漏除 1+b 的陷阱；
  - 基期比重题里出现现期比重 → 没修正的陷阱；
  - 隔年增速选项里出现 R1+R2 → 漏了 R1×R2。

## 三、除法 A/B 的五种算法（按优先级挑）

1. **百化分**：分母或结果靠近常见分数。÷1.143 = ×7/8；÷1.125 = ×8/9；×14.3% = ÷7；×9.1% = ÷11。小分互换：1/13≈7.7% ⇔ 1/7.7≈13%。
2. **拆分法（基准数＋余数）**：分子拆成“分母的整倍数或整百分比 ± 余数”。
   - 2715/1654：先扣 1 倍 1654，余 1061；1654×0.6≈992，余约 69，69/1654≈4% → 1.64。
   - 332/688：688 的一半是 344，332 = 344 − 12，12/688≈1.7% → 50% − 1.7% ≈ 48.3%。
3. **同乘凑整**：分母乘一个小数变成整数。÷25 = ×4÷100；÷125 = ×8÷1000；÷33.3 ≈ ×3÷100；÷14.3 ≈ ×7÷100；÷16.7 ≈ ×6÷100。例 437/25 = 437×4/100 = 17.48。
4. **估商代入（反向乘法）**：把除法变成乘法验选项，选项差距小时最快。先代中间值，一次排除两边。例 110.7/85.8 万人，选项 12366 与 12902：85.8×1.3 = 111.5 > 110.7，所以略小于 1.3；85.8×1.29 = 110.7 → 12902。
5. **截位直除（保底）**：分子不动、分母截 3 位，商出前两三位。用在 d<3%、或分母没有任何可用结构时。复盘时用它要写出理由（选项差多少、为什么前四种不够）。

## 四、乘法

- 拆成整数比例：×1.5 = 加一半；×1.25 = ×10÷8；×0.125 = ÷8；×0.9 = 减 10%；×15% = 10% + 5%；×19.5% ≈ 20% − 0.5%。
- 百化分：×14.3% = ÷7；×8.3% = ÷12；×4.5% ≈ ÷22（由 1/11=9.1% 减半得到，不用死背）。
- 两数相乘截位：各截 2 位，一个进一个舍，误差相抵。

## 五、按题型的考场首选（复盘逐题对照）

| 题型 | 首选动作 | 什么时候换方法 |
| :--- | :--- | :--- |
| 基期 B/(1+r) | r≈1/n：B×n/(n+1)（先算增量 B/(n+1) 再倒扣）；\|r\|≤10%：B×(1−r)，真值略大于它 | r 无近似分数且 d<3%：估商代入或直除 |
| 隔年基期 | 先 R间 = R1+R2+R1R2，再按上一行做一次 | 禁止连除两次 |
| 增长量 B×r/(1+r) | r≈1/n：B/(n+1)，r 比 1/n 略大则结果略大；\|r\|≤10%：B×r 再减去它的 r 倍 | 只有 d 明显大于 r 时才能直接 B×r |
| 增长量比较 | 大大则大；一大一小比 B×r；r 相差大（如 50% 对 10%）时比 B/(n+1) | 两者 B×r 很接近：百化分精比 |
| 一般增长率 X/A、B/A−1 | 先做差（B−A），再用拆分法或估商代入除以 A | — |
| 比值/平均数增速 (a−b)/(1+b) | 先算 a−b，再按 (a−b)×(1−b) 修正；b>0 结果必略小于 a−b | 选项里有 a−b 本身，必是陷阱 |
| 现期比重 A/B | 结果靠近常见分数用百化分；否则拆分法或估商代入 | d<3% 才直除 |
| 基期比重 | 先比 a、b 定基期比重比现期高还是低，排除两项；再用 现期比重×(1+b−a) 近似 | a、b 都很大时用原式 |
| 比重差 | 定升降 → \|差\|<\|a−b\| 卡上限 → 仍有两个候选才算 (A/B)×(a−b)/(1+a) | — |
| 年均增长量 | (末−初)/n，n＝末年−初年；求和用高位叠加/尾数 | — |
| 年均增速 | 先用 1+nr 得上限，再用乘方常数或代入选项；r 大时必须代入 | 二项式：(1+r)ⁿ ≈ 1+nr+C(n,2)r² |
| 混合增速 | 居中、偏向基期大的一方，先排除两项 | 要具体值才用线段法 |
| 分数比较 | 一大一小直接看 → 倍数法 → 差分法 → 两个分数交叉相乘 | — |
| 加减 | 选项尾数不同用尾数法；多项求和高位叠加；减法凑整补数 | — |

乘方常数：1.05⁵≈1.28，1.06⁵≈1.34，1.08⁵≈1.47，1.1⁵≈1.61，1.15⁵≈2.01，1.2⁵≈2.49；1.1²=1.21，1.1³≈1.33，1.2³≈1.73。翻番年数≈72÷(增速百分数)。

## 六、本场真题示范（2026-10-20 粤考日练）

- **增长量，r=4.5%**：现期 48.3，选项 2.08 / 2.17（d≈4%，而且 2.17/2.08≈1.045，正是漏除 1+r 的陷阱）。百化分：4.5%≈1/22 → 48.3/23≈2.10，选 2.08；或 48.3×4.5%=2.17，再减去 4.5%（约 0.1）→ 2.07～2.08。错误做法：|r|≤5% 直接 B×r。
- **平均数增速**：a=9.8%，b=3.2%，选项 6.6% / 6.4%。a−b=6.6%，6.6×(1−3.2%)≈6.4%。选项里的 6.6% 就是漏除 1+b 的陷阱。
- **分数比较** 2.8/72.2 与 4.2/104.2：倍数法，分子 4.2/2.8=1.5 倍，分母 104.2/72.2≈1.44 倍，分子倍数大 → 右边大。不用算出 3.88% 和 4.03%。
- **人均用电** 110.7 亿千瓦时 / 85.80 万人：估商代入，85.8×1.3=111.5 偏大一点 → 1.29 万千瓦时/人 → 12902。

## 七、综合分析（正误判断）

1. 先看问法：问“不能推出/错误的是”，草稿顶部画大【×】，每项判完写 √ 或 ×。
2. 不按 A→D 顺序，按难度挑：读数、加减 → 简单倍数/比重 → 增速、比重升降定性 → 基期、年均、复杂计算最后。
3. 单选题找到一个确定的答案就停，剩下的不验。
4. 每项判断也按上面的选项差距原则：“高于 8.5%”这类阈值判断只要算到能和阈值分开即可。

## 八、复盘 `#### 考场解法` 的写法要求

1. 第一行写选项判断：选项最小差距约多少、有没有陷阱值、哪些选项可以直接排除。
2. 再写列式，然后写**选的技巧和一句理由**（例：“4.5%≈1/22，百化分误差约 1%，选项差 4%，够用”）。
3. 技巧给出 1～2 行可以在草稿纸上照写的算式，不写长除法竖式。
4. 只有在 d<3% 或技巧不可用时才写直除，并点明“这里直除最稳的原因”。
5. 用户草稿用的方法若误差够用，先说这一步对，再给更短的写法；不因为他没用直除就判错。
