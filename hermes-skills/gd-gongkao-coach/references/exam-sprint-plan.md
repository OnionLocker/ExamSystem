# 考前约70天：Hermes 驱动的提分计划

用户确认：由 Hermes 主导选择学习目标，继承历史进度，不从零开始；时间有限，以考场可兑现的得分为目标。计划于2026-09-24建立。USER.md 已记录目标广东省考、有多次实战经验、历史自述行测最高78分；这是学习背景，不是当前整卷基线，不安排从头通学基础。已记录每日11:00起可备考、可用约7—8小时，15:00—16:30固定运动，18:30—22:30为黄金时段。按此制定约7小时有效学习骨架；当天用户给出时间或作息变化则优先调整。确切笔试日期尚未核实，约70天来自用户当前描述，不当作官方公告。

## 每次开始学习

1. 使用消息中已有的最新学情快照；没有则只调用一次 `python3 scripts/learner_snapshot.py --compact`。快照已经包括历史表现、近期练习、最近计划的进度与验收结论、约定复测，不要另查库拼学情。
2. 优先承接尚未完成的学习目标与到期短测。历史暂定判断不是“没学过”；没有结构化过程记录也不要求整批重新测评。记忆中的学习经历可以定位原始证据，但不能把“老师讲过/模型说掌握”直接认证为掌握。
3. 推荐一个主攻和一个短测，明确本次题量、时间预算、要改的具体动作、结束条件。候选列表不是必做清单。不要反复问用户选哪个知识点；用户点名则跟随点名，不点名则你决定。
4. 决策说明只需一句：为什么值得现在做。依据目标考试的考频/分值结构、当前失分和短期可改善性；没有可靠考情依据时说暂定，不能杜撰每小时能涨几分。
5. 形成实际任务后用现有 `python3 scripts/daily_plan_state.py save --merge --items-json 'JSON数组'` 保存当天计划。每项显式指定稳定 id，沿用原 id/batch_id；--merge 保留未涉及的任务、扩展字段和进度，不因换会话重建整天。每个任务保留 `reason`、`minutes`、`exit_criterion`；复盘后补 `verdict`、`followup_date`。复测完成用原计划日期 `--date YYYY-MM-DD` 在原任务设置 `followup_done=true`，不让它每天重复到期。

题目任务按实际题数计 count。讲解、申论写作、整卷复盘等非逐题任务用 `task_type:"manual"`、`count:1`，由实际完成后 `daily_plan_state.py complete --item <id>` 标记；不可因同模块做过一道题自动完成。任务完成与掌握认证是两回事。脚本规范化会保留上述扩展字段；保存前沿用快照里的最近计划，不丢失旧任务。新的一天可以安排新任务，不复制昨天已完成题量。

## 选择与停止规则

- 主攻一般35—45分钟，包括讲解、练习和关键复盘。证据不足先2—3道新题，10—15分钟，边学边确定问题。
- 模型不会：解释识别条件与一条关键关系，再给少量新题；会但慢：压缩草稿步骤、减少回退；算错/审题错：练一个具体检查动作。不要每次重讲整章。
- 达到本次验收动作就结束，安排2—3天后的短测；进一步稳定性复核约7天。暂时未达标不等于必须当晚清零所有错误。
- 连续两轮有效新题正确率低且无改善：停下加量，改教法/降低起步复杂度，或者暂缓低收益难点。系统 plateau 只是提醒，不替代教研判断。
- 知识债优先，但不是禁止其他高收益常考点的锁。累计错多、练习量大、距离上次久，都不能单独证明值得主攻。
- 同族距上次不超过1天，用户未点名时不作为新的主攻；同场练后纠错可以完成，但不能把同题记成新的独立验证。
- 常考基础、中等难度可避免失分优先；数量偏难题若成本高，允许制定考场跳题策略。不能承诺押中原题或保证上岸。
- 每周一次完整限时行测检验。比较整卷完成率、分模块正确率/耗时、到最后未作答的题，决定下一周预算。专项高分不能代替整卷检验。目标考试包含申论时，必须保留申论时间。

## 默认作息：约7小时有效学习

| 时间 | 环节 |
|---|---|
| 11:00—11:20 | 到期短测，承接上次任务 |
| 11:20—12:05 | 今日唯一主攻，围绕一个失分动作 |
| 12:15—13:00 | 辅助模块混合题，或承接未完成的限时训练 |
| 14:00—14:45 | 上午关键题复盘，独立复现方法 |
| 15:00—16:30 | 固定运动，不安排学习任务 |
| 16:45—17:30 | 政治、常识、科推轮换，主动回忆与练习 |
| 18:30—19:20 | 行测模块限时训练，练速度与取舍 |
| 19:30—20:20 | 对应复盘，记录丢分原因和草稿改进动作 |
| 20:30—21:30 | 申论：小题或论证实写及反馈 |
| 21:40—22:20 | 已学方法再现、变式短验收；达标可提前结束 |
| 22:20—22:30 | 保存结论、复测日期和明日承接 |

有效时间合计6小时50分钟，其余空档用于吃饭与休息。不要为了凑够8小时深夜加量。一天仍是一主一辅：主攻只一个，其他环节用于限时应用、复盘、保持和必考科目覆盖，不是不断开新考点。需要整套考试时按目标考试实际时限合并相邻时段，替换常规训练，不叠加题量。资料与判断、言语等模块的具体预算由每周整卷表现调整。

## 时间不足时：每日4小时缩减版

| 环节 | 时间 | 交付物 |
|---|---:|---|
| 到期短测/热身 | 15分钟 | 2—3道新题，确认保持情况 |
| 今日主攻 | 45分钟 | 5—8道基础/中等新题，修正一个失分动作 |
| 轮换模块限时训练与复盘 | 50分钟 | 一组混合题，记录取舍与耗时 |
| 申论 | 60分钟 | 一道小题或一段论证，按题目要求逐项核对 |
| 政治/常识/科推轮换 | 25分钟 | 回忆提取与针对性练习，避免只看讲解 |
| 已学方法再现/错题变式 | 30分钟 | 不看解析复现关键关系，必要时用新题验证 |
| 日结与明日承接 | 15分钟 | 今日具体进步、未解决动作、复测日期 |

目标考试不考申论时，将申论时段分配给目标考试科目。申论基础薄弱时从材料定位、小题要点开始，不把60分钟全部用在阅读AI讲解。现有申论步骤资源不足时，以题目要求和可靠评分参考为依据，明确缺口，不编造官方分数。

每天只有2小时：10分钟短测 + 30分钟主攻 + 30分钟模块训练复盘 + 35分钟申论 + 15分钟回顾。缩减时仍保留作答后的复盘；不要把额外时间全部加到同一数量难点。

## 首周安排（模块轮换是暂定，不宣称这些模块就是用户弱项）

| 日次 | 行测主线 | 必须完成的校准 |
|---|---|---|
| 第1天 | 承接增长量与现期推算等已有任务，从失分候选选一项；判断或言语短测 | 继承历史与已知作息，核对当天时间变化，不全面重测 |
| 第2天 | 言语或判断中的一个常考基础考法 | 记录一项能减少失分的动作 |
| 第3天 | 数量基础/中等题；科推短测 | 约定单题取舍，不继续堆最值/概率难题 |
| 第4天 | 资料或判断的混合限时训练 | 复测第1天的目标，按结果调整 |
| 第5天 | 言语与本周有收益的另一模块轮换 | 检查速度和无谓回退，不只算正确率 |
| 第6天 | 按目标考试时限完成一套行测卷 | 替换当天常规训练；剩余时间复盘关键失分，不再叠加一整天题量 |
| 第7天 | 周结、保温短测、申论限时训练 | 比较模块表现，确定下一周一个主要改进方向 |

已有近期完整限时卷及其报告时优先复用，不因换评估口径强制重做。Hermes 每日可根据真实表现调整模块，保持跨模块覆盖和申论预算；不要机械照表刷题。

## 约70天三阶段

- 前14天：衔接历史画像，边学边补最小诊断，只补已经暴露的基础漏洞、反复失分动作和配速问题，不从头通学。每周一次限时整卷。
- 中间35天：主攻短期可改善问题，增加混合题和限时取舍；每周一套完整行测，另一次完整模块计时。申论每周至少一次完整限时写作及复盘，其余天训练小题/论证。
- 最后21天：每周1—2套完整行测，以复盘消化能力为上限；收敛答题顺序与跳题策略，复习已学内容。原则上不大范围新开偏难低频点。临考最后几天减量，保持作息和手感。

以上阶段随真实倒计时调整，不许在考试临近时仍机械执行“前14天”。缺整卷模块基线时不编造模块学习比例；第一周的限时表现决定下一周增减。

## 学习强度记录

日历按已计时学习区间的并集分档，同一时间开番茄钟、做题、复习只算一次，跨午夜按北京时间分日。正确率只参与能力评估，不加学习强度分。重做的计时保留，AI新题与重做题量分别列出。0—30分钟、30—60分钟、1—2小时、2—3小时、3—4小时、4—6小时、6—8小时、8小时以上是显示区间，不是推荐加量目标。

Hermes 对话只记录学习内容和依据，不猜分钟数。教学、纸笔、申论或线下复盘时可开现有番茄钟，休息要暂停。旧成绩、视频、笔记和聊天仍保留；缺计时区间显示“时长未知”，不把题量、视频长度或模型估时当成实际学习时间，也不能把未知说成没学。已计时是记录到的投入，不认证持续注意力和学习成效。

## 模型使用

日常推荐、按固定口径讲解、计划记账可以先沿用用户现有 Gemini Flash。模型名称不是能力认证，也不要为换模型耗费几天。若连续漏读快照、误读草稿、改写客观判分或忘记写评估，先纠正流程；复杂推理、解答争议或连续两轮教而无效时，才请更强推理模型或可靠解析复核关键题。题目质量沿用现有出题流程，不新增审核环节。
