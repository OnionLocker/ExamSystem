1. 官方直连优先：广东人事考试网 `rsks.gd.gov.cn`、广东省委组织部 `gdzz.gov.cn`、广东省人社厅 `hrss.gd.gov.cn`、地市政府官网。
2. 搜索引擎只作线索：搜狗搜索在当前环境可返回广东省考结果，适合作为百度风控时的备选入口。
3. 百度移动搜索可能触发“百度安全验证 网络不给力，请稍后重试”；不要尝试绕验证码，改用官方站点/搜狗/站内检索。
4. Playwright 可用于普通 JS 渲染或 UA/cookie 问题，不用于破解验证码。
5. 抽取工具优先 `requests + bs4/lxml`；需要更强正文抽取时可考虑 `trafilatura`/`readability-lxml`。

## 行测题型结构（以2025/2026趋势为参考）
- 总体：约 90题 / 90分钟 / 满分100分。
- 政治理论：约10题，可能含判断、单选、多选。重点是习近平新时代中国特色社会主义思想、党的会议精神、广东高质量发展、粤港澳大湾区、百千万工程、新质生产力、基层治理等。
- 常识判断：约5题，法律、科技、历史人文、广东省情、时政延伸。
- 言语理解与表达：约15题，通常选词填空约5题、片段/阅读理解约10题。
- 数量关系：约15题，数字推理约5题、数学运算约10题。
- 判断推理：约25题，常见图形推理约10题、类比推理约5题、逻辑判断约10题；实际以当年真题/权威机构解析为准。
- 科学推理：约5–10题，广东特色，偏初中物理（力学、电学、光学、压强、浮力、杠杆）、生物、化学基础实验和少量地理/科学常识。
- 资料分析：约15–20题，目标18–20分钟完成、正确率90%左右。

## 申论结构
- 150分钟 / 满分100分。
- 常见题型：概括归纳、综合分析、提出对策、应用文/贯彻执行、大作文/议论文。
- 分卷可能包括县级以上、乡镇、行政执法、公安专业相关卷等。用户当前目标是公务员岗，不要沿用警察岗单一路线。

## 用户训练优先级
1. 申论：58–60 → 65+，冲68。
2. 科学推理：专项补短板。
3. 言语：建立稳定方法，降低波动。
4. 资料分析：保持强势，做稳定拿分器。
5. 判断推理：保证大模块不塌。
6. 数量：选择性拿分，不恋战。
7. 政治理论：每天小剂量积累。

## 数资模块专属训练系统
用户服务器上有 `ExamSystem`（`/home/ubuntu/ExamSystem/`）自建数资练习平台。
- 覆盖 数量关系 22子题型 + 资料分析 16子题型 + 基本计算 + 计算辅助 + 数字推理
- 段位系统（青铜→王者），晋升模式计段位，训练模式自由刷
- 目标段位：数量关系→钻石（≤42.5s/题，≥88%正确率），资料分析→大师~王者（≥92%正确率）
