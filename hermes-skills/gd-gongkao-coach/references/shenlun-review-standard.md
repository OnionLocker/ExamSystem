# 申论复盘评判标准（广东县级卷）

> 本文件由用户维护。改这里就改了评分和点评口径：
> - 批改脚本 `scripts/shenlun_grade.py` 每次评分都读取「通用」和对应题型章节，原文交给阅卷模型；
> - 「评分参数」里的 JSON 由程序读取，控制部分命中给几成分、作文档次分数段等；
> - Hermes 复盘点评按「点评要求」写。
> 章节标题（`## 通用`、`## 归纳概括` 等）不要改名，程序按标题取段落。

## 评分参数

```json
{
  "partial_ratio": 0.5,
  "expression_levels": {"A": 1.0, "B": 0.5, "C": 0.0},
  "dispute_policy": "lower",
  "essay_levels": [
    {"name": "一类文", "min": 0.83, "max": 1.0},
    {"name": "二类文", "min": 0.63, "max": 0.82},
    {"name": "三类文", "min": 0.43, "max": 0.62},
    {"name": "四类文", "min": 0.0, "max": 0.42}
  ],
  "essay_off_topic_level": "四类文",
  "overflow_note_only": true
}
```

- `partial_ratio`：部分命中给该要点分值的几成。
- `expression_levels`：表述分 A/B/C 三档各给满分的几成。
- `dispute_policy`：两遍批改判得不一样时，`lower` 取低分，`higher` 取高分。
- `essay_levels`：作文各档对应满分的比例区间，给分取区间中点。
- `overflow_note_only`：`true` 时超字数、字数不足只提醒不扣分。

## 通用

- 按要点采点给分，不凭整体印象打分；一句话只能支撑它真正表达的那个要点。
- 同义表述、换个说法都算命中；只写「加强领导」「提高认识」「形成合力」这类与材料无关的套话不给分。
- 要点答到一半、或表述含糊到要阅卷人去猜，判部分命中。
- 答案与设问对象、范围不符（比如问做法答了成效），对应要点不给分。
- 分条清楚、语言规范给表述满分；条理基本清楚给一半；混乱或口语化严重不给。

## 归纳概括

- 看全不全：材料里的做法、问题、成效是否都找到，漏一个扣一个。
- 看准不准：用材料原词或规范概括，不能概括错对象，也不能把原因写成做法。
- 看精不精：有总括词再接具体内容；只抄材料原句而没有概括，判部分命中。

## 综合分析

- 有表态或含义解释：对引号里的说法先解释清楚。
- 有分析：每层分析要有材料依据，说清为什么、怎么体现；只解释不分析的，分析类要点不给分。
- 有落脚：结尾提出启示或做法的，按要点表给分。

## 提出对策

- 对策要针对材料里的问题，问题和对策对不上的不给分。
- 对策要具体可行：写出谁来做、做什么、怎么做；只有口号的判部分命中或不给分。
- 借鉴材料经验时要转化到本题对象上，照搬与问题无关的经验不给分。

## 贯彻执行

- 格式要素按格式要点逐项判：标题、称谓、落款日期等按文种要求，缺一项扣一项。
- 身份、对象、语气要贴合：对群众通俗亲切，对上级规范简洁；写错身份或对象的，表述分降一档。
- 正文要点按要点表采点；把公文写成议论文的，表述分不给。

## 文章写作

- 立意定上限：偏离题目与材料主旨的最高三类文，完全偏题按四类文。
- 结构：标题、开头亮出总论点、三个左右分论点、结尾升华，缺一块降一档。
- 论证：分论点要有材料或实例支撑并展开分析；通篇罗列口号的论证最高三类。
- 语言：规范、流畅、符合机关文风。
- 字数不足下限会在报告里提醒。

## 点评要求

- 复盘开头不写总评，第一行就是 `### 第1题 · 题型`（只交了部分题时，只写交了的题）。
- 每题依次写：
  - `**得分**：X/满分`（只抄评分报告，不改分）；
  - `#### 失分在哪`：逐个列出未命中、部分命中的要点，引用材料原句说明这一分该从哪里找到；
  - `#### 正确做法`：按 `solver-canon/08-shenlun.md` 对应题型的步骤，示范这题该怎么审题、找点、归类；
  - `#### 下次动作`：1 到 3 条考场上能直接照做的动作。
- 「两遍有分歧」的要点要单独说明：对照材料说清楚你认为该不该给分，但不改报告分数。
- 作文点评按立意、结构、论证、语言逐项写，并给出提纲级的修改建议，不代写全文。
- 只交了一道题的题型特训，最后补一句这类题的通用提醒。
