# 陈折桂方法论 — 核心要点提炼

来源：陈折桂经验帖（从一个月模考79到省考90/统考88）
B站账号：陈折桂 / 韩江折桂 系列视频

## 核心哲学

1. **复盘 > 刷题量**：一道题复盘时间是答题时间的3-5倍是正常的。前期沉下心来复盘，是为了后期少复盘。
2. **不要用题海战术代替复盘归纳**：达到5000题基础刷题量后，提升主要来源于复盘而非继续刷。认真100题复盘 > 不带思考刷300题。
3. **分数高低不能赖刷题不够**：很有可能是方法问题——没有计划、不会复盘。

## 三阶段法

### 阶段一：打基础（~50天）
- **学习顺序**：资料 → 判断 → 言语 → 数量（政治常识晚点学）
- 前30天以听课为主，只做讲义里的题；后20天开始做套卷+组题
- 尽快把基础过一遍，不要一直耗在单个板块反复看课
- 完成基础后做3张摸底卷，分析得分效率，确定做题顺序

### 阶段二：强化提升（看完基础课到考前1个月）
- 保持刷卷+复盘+每周模考
- 两天一套套卷 + 每天100道组题
- 周日参加粉笔模考
- 优选真题：近5年国考+京鲁江浙粤省考选调（60多份，5000多题）

### 阶段三：限时冲刺（80+或考前2周）
- 100分钟→90分钟→84分钟三阶段压缩
- 84分钟阶段预留涂卡时间
- 模拟涂卡（买答题卡练习）

## 分板块方法

### 资料分析（最重要的板块，广东占比22.2%）
- **最早学、投入最多时间**：早点学早点练才来得及考前达到合适速度
- **不看选项，一算到底**：用通用方法而非秒杀
- **四个环节**：读题（快速抓主干识别题型）→ 找数 → 列式 → 计算
- **录屏复盘**：每次做完挑出超过1分钟或做错的题，回放看慢在哪错在哪
- **后期提速法**："回头望月"看前四题选项分布

### 言语理解
- 跟定一个老师（推荐：红领巾/巾哥），不要换
- **逻辑填空三对应**：逻辑对应、语境对应、搭配对应
- 二选一摇摆不定 → 该蒙就蒙

### 图形推理（广东重点）
- 立体题（广东考得多！立体拼合/三视图/截面/六面体）→ 重方法而非刷题
- 一眼看不出就跳

### 逻辑判断
- **从后往前读题**：先看题干问什么 → 找结论 → 看依据
- 加强削弱：找逻辑漏洞
- 翻译推理：直接在题干上画箭头

### 数量关系
- **循序渐进法**：5→10道递增
- **超60秒就跳**
- 高频题型优先：和差倍比、行程、工程、几何、经济利润

### 科学推理（广东特色）
- 刷广东真题+粉笔模考题即可
- **不用做江浙沪中考题**

### 政治理论（2025新增单列，约15题）
- 跟一个系统课（李卜/李铁/考研肖秀荣）
- 考前听条鸟/颜培天冲刺

## 做题顺序与时间分配（广东省考 90分钟）

**资料 → 数量 → 判断 → 言语 → 政治 → 常识**

| 板块 | 参考用时 | 得分率参考(80%) |
|------|---------|----------------|
| 资料分析 | 18min | 13/15 |
| 数量关系 | 25min | 12/15 |
| 判断推理 | 22min | 20/25 |
| 言语理解 | 7min | 8/10 |
| 政治理论 | 8min | 12/15 |
| 常识判断 | 3min | 3/5 |
| 涂卡 | 5min | - |
| 缓冲 | 2min | - |

原则：
- 越紧张的板块越先做
- 得分效率高的优先做
- 数推/图推一眼看不出就跳

## 刷题量参考
- 选调时刚过1万题，省考时刚过1.5万题 + 二十几次模考
- 真题卷无需反复刷：前中期第一遍、考前一个月第二遍，第三遍没必要
- 有价值的近年真题就那么多，有些刷题量就是无用功

## 模考观
- 从第三周开始基本全勤参加模考
- 模考是用来训练做新题的反应和时间分配的，模拟考场的紧张感
- 成绩不必太在意，主要参考击败比
- 2024年年中起模考注水严重（提前获取试卷、抄直播间答案），成绩可信度下降
- 判断一个人水平要看讲题的思路，不是模考分数
- 考完可以看B站UP主复盘视频（安哥陈怀安、青菜白玉汤、大谷工等）

## 考友与信息搜集
- 组建7人备考小队，专业不同、互不藏私 → 全员上岸
- 找水平相近、专业不同的考友组队，不要加几百人的交流群
- 警惕打着找考友的幌子做无关学习的事情
- 一个人力量有限，没有信息搜集能力就找考友一起进步

## 考场技巧
- 考前喝咖啡/咖啡因注意剂量（不超过100mg），提前测试自己耐受度
- 考前到教室门口先做两篇资料热身
- 84分钟阶段要当作82甚至80分钟来冲
- 考前1个月或平时先测试自己对咖啡因的敏感程度
