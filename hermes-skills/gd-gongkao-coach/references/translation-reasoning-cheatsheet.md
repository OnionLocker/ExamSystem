# 翻译推理 · 关联词记忆与考场流程

> 用户于2026-07-29验证通过。这套记忆口诀必须作为标准教学内容使用。

## 三大记忆锚点

### 锚点一：只看一个字——「才」

**「才」字前面是箭头尾巴。**

- 「只有 A **才** B」→ **才**前面是 A → A在箭头尾巴 → B → A
- 「除非 A **才** B」→ 同上

考场遇到任何带「才」字的句子，直接认定：**才前面的东西，放在箭头右边（箭头尾）。**

### 锚点二：只看一个词——「否则」

**「否则」= 非前面 → 后面。**

| 原文 | 翻译 |
|------|------|
| A 否则 B | ¬A → B |
| 除非 A 否则 B | ¬A → B |
| 除非 A 否则不 B | ¬A → ¬B |

**注意**：「除非 A 才 B」≠「除非 A 否则 B」：
- 「才」= 后推前（B→A）
- 「否则」= 非前推后（¬前→后）

### 锚点三：考场上永远只干一件事——找逆否

> **原命题 A → B 成立，等价于 ¬B → ¬A 成立。**  
> 考场上 90% 的翻译推理题，考的就是逆否命题。

逆否转化两个动作缺一不可：
1. **箭头反转**（A→B → B→A）
2. **两边加非**（B→A → ¬B→¬A）

**只做第二个（加非）没做第一个（反转箭头）→ 写出的是「否命题」❌，逻辑无效。**

## 考场四步操作流程

| 步骤 | 动作 |
|------|------|
| ① | 看到关联词，写翻译（A→B） |
| ② | 在原翻译下方，立刻写逆否（¬B→¬A） |
| ③ | 拿着选项跟这两条逐一比对 |
| ④ | 排除「肯定后件」「否定前件」的选项，剩下的就是答案 |

## 全量关联词速查

### 前推后（A → B）
- 如果A那么B、只要A就B、所有A都B、凡是A都B、若A则B、A就B、为了A必须B、A离不开B

### 后推前（B → A）
- 只有A才B、除非A才B、A是B的前提、A是B的基础、A是B的必要条件、A是B的关键、不A就不B、A是B的必经之路

### 特殊硬规则
- 除非A否则B → ¬A → B
- A否则B → ¬A → B（与上等价）

### 且/或逻辑
- A且B（A∧B）：两个同时成立
- A或B（A∨B）：至少一个成立
- 要么A要么B（A⊕B）：二选一

## 常见陷阱

| 陷阱 | 错误推理 | 正确规则 |
|------|----------|----------|
| 逆命题混淆 | A→B ≠ B→A | 肯后无效 |
| 否命题混淆 | A→B ≠ ¬A→¬B | 否前无效 |
| 方向混用 | "只有才"与"如果就"搞反 | 看"才"定方向 |
