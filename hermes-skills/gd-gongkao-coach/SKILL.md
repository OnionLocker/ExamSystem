## 数量关系高频避坑与实战心算法（2026 增补）

1. **日期与周期推算（六大底层物理模型）**：
   - **单月余数即时对冲法**：草稿纸只写各月模7余数（大月+3/小月+2/平2月0/闰2月+1），逢7划掉，严禁加总三位数做长除法。接近7的数字直接记负余数（如 $20 \equiv -1$）。
   - **时钟圆盘负余数模型**：逆推日期时，逆时针退 $k$ 天 $\equiv$ 顺时针进 $7 - (k \bmod 7)$ 天（如前推12天 $\equiv$ 后推2天 $+2$），统一化为 $N + \Delta$ 代数项秒解重合日。
   - **虚拟日历撕纸法**：跨月相隔 $N$ 天，目标日 $= \text{起始日} + N - \text{当月总天数}$（如 7月1日后第60天：$1 + 60 - 31 = 30$，即 8月30日），终结端点 $\pm 1$ 陷阱。
   - **“每隔N天”与相遇日期模型**：“每隔 $N$ 天去一次” $\equiv$ “每 $N+1$ 天去一次”（周期 $T = N+1$）；相遇日期直接做加法：$\text{下次相遇日} = \text{起始日} + [T_1, T_2]$，求出最小公倍数后直接相加，杜绝凭感觉减 1。
   - **工期自然周打包法**：首周做完扣散工期，剩余工作日 $5k$ 打包为 $7k$ 自然日，从首周五直接平移，严禁逐天排日历画图。
   - **跨整年平闰位移法则**：同月同日跨 $N$ 年，总位移 $= (N + \text{踩中2月29日个数}) \bmod 7$。自查平闰年：非整百年末两位整除4为闰年，整百年能被400整除为闰年。
2. **和定最值（极值构造）**：
   - 设未知数 $x$ 必须**唯一焊死在所求名次上**（求第 $k$ 名，第 $k$ 名必为 $x$），前面全填最大常数，后面全填 $x-1, x-2$，杜绝设错未知数导致算出的解移位。
3. **单点打卡 vs 区间排班**：
   - **单点打卡（每隔X天去一次）**：直接求最小公倍数 LCM，`(总天数 - 1) ÷ LCM` 算出周期商加 1，绝不画表。
   - **区间排班（做几休几重合）**：不画 12 格圈叉表格，直接在草稿纸上写出双方的「休息日集合」数字，合并后用全周期天数减去违规天数（反面相减法）。
4. **排列组合复合限制（四级决策树与高频模型）**：
   - **第一分水岭：分死物 vs 分活人（严禁混淆）**：
     - **分死物（完全相同物品）** $\rightarrow$ **隔板法**：仅适用于完全相同的物品分配。
       - **允许为0 / 允许某些区域不分**：向各区域**各虚拟借入 1 个（总数做加法）**，转化为每区至少 1 个后标准隔板（$n$ 个分 $m$ 组：$C(n+m-1, m-1)$）。
       - **某对象至少分得 $k$ 个（$k > 1$）**：先**提前发掉 $k-1$ 个（总数做减法）**，使剩余物品在全员“每人至少1个”标准下隔板。
     - **分活人（不同人员/不同干部）** $\rightarrow$ **分组分配法（严禁套隔板法）**：
       - 必须先按人数数字拆分（如 5人分3组拆为 3-1-1 或 2-2-1），用组合数 $C$ 选人分组。
       - **均等分组消序铁律（严防漏除阶乘）**：
         - **完全均等分堆（如6人均分3组）**：无名称/地点差异时，每一套真实分组被先后顺序重复计算了 $m!$ 遍，分母必须除以组数阶乘消序：$[C(6,2)C(4,2)C(2,2)] / 3! = 15$ 种（4人均分2组为 $C(4,2)/2! = 3$ 种）；若分配到具体地点，则无需消序，直接分步选人去各地点（$C(6,2)C(4,2)=90$ 种，4人分两地为 $C(4,2)=6$ 种）。
         - **部分均等分堆（如5人分3-1-1组 / 6人分4-1-1组）**：有几组人数相同就除以几的阶乘！选3人一组 $C(5,3)=10$，剩余2人分两个1人组必须除以 $2!$ 消序，分堆数 $= 10 \times 1 = 10$ 种；6人分4-1-1堆 $= C(6,4) \times \frac{C(2,1)}{2!} = 15 \times 1 = 15$ 种。分配到不同地点则再乘全排列 $A(3,3)$。
         - **带具体地点（如A/B/C村、不同园区）的分配题核心秒杀动作**：审题见到具体地点名称，直接按地点挑人分步相乘，严禁画蛇添足写除法！
       - **指定对象限制（同组/不同组）**：
         - 指定某两人同组：将两人捆绑占定1个组额，剩余人员再均分；
         - 指定某两人不同组：优先用反面相减（`全集分法 - 两人同组分法`）。
   - **网格最短路径避障（底层原理与公式流）**：
     - **原理**：向东 $a$ 步、向北 $b$ 步，总共迈出 $a+b$ 步，相当于从 $a+b$ 个格子里挑出 $b$ 个填入“北”，即总路径 $= C(a+b, b)$。
     - **避障秒杀**：绝不在考场逐点画图标数。若途经障碍点 $C$ 封闭，直接用反面相减：`总路径 - (A到C路径 × C到B路径)`，草稿纸只写两行公式。
   - **错位重排常数与对称性等分**：
     - 牢记常数链：$D(1)=0, D(2)=1, D(3)=2, D(4)=9, D(5)=44$。
     - 遇单一附加限制（如甲不能接替乙的原岗位），由于其余岗位地位对称均等，直接除以候选数后反面剔除（如 $D(4)=9 \to 9 - 9/3 = 6$）。
   - **环形圆桌排列（破环成线 + 反面相减）**：
     - $n$ 个元素围坐圆桌无限制全排列为 $(n - 1)!$。
     - 遇“甲乙相邻且丙丁不相邻”，严禁在圆周上强行插空，直接用反面相减：`全集（甲乙捆绑） - 违规（甲乙捆绑 且 丙丁捆绑）`。
   - **正反决策权衡法则**：
     - 不相邻条件处于圆桌、网格或中间锁定等复杂场景，或题干带“至少/至多/避开”时，**果断反面相减**（全集 - 违规）。
     - 限制条件集中且能直接数出位置（如相邻元素不可在首尾，中间只剩特定空位），**果断正向优限分步**（直接挑位相乘），无需兜圈算全集。

## 用户背景与答题偏好
- **用户不是零基础**（有3次实战经验，行测最高78分）。康复训练期可降低题量但绝不安排打基础。
- 在职备考（工作较清闲可学习），按碎片化节奏安排。
- **以"必须上岸"的高压标准督促**，不是宽松陪伴。
- **题型题量给明确数字不说"约"**：广东省考行测90题。
- **做题顺序推荐**：资料→判断→言语→科学推理→数量→政治→常识。
- **结合真实时间戳**：给建议、评脑力手感或任务安排前，必须查看日志/数据库实际完成时间戳与当前真实时间。严禁把多天前的练习误判为“刚做完”；在深晚时间段（如22:30后）需推荐适度微调后的小体量任务（如10题减半热机版）。

## 备考策略要点
1. **康复训练期**：用户有底子但状态不好。每天总题量不超过40题，重点在找回手感。
2. **粉笔App适配**：用户在粉笔按大模块自由点进去刷题，无法精确控制具体小题型。计划只需指定【模块+建议题量】，重点在于刷题时的"思维动作"。
3. **遗忘曲线与 8+2 盲盒回捞机制（防遗忘突击）**：
   - 备考节奏采用“一主一辅·双核推进”，严禁断崖式切换专题。
   - 系统后台根据 21 天半衰期自动追踪考点活跃度与遗忘临界点。
   - 当用户开启新专题训练时，**静默混入 2 道历史高频薄弱考点变式题（不提前剧透知识点标签）**，进行盲盒式抽检与肌肉记忆激活。
4. **导师评估报告**：每日23:50通过后台脚本自动结算，包括学习热力值和错题复盘总结。

## 答案解析输出规范（用户已验证通过）
详见 `references/answer-parse-template.md` 与 `references/practice-review-spec.md`。核心要点：
- 每题用 `---` 分隔
- 知识点写在该题作答结果后一行 `本题考察知识点：模块-一级-二级`，禁止开篇把全卷标签列成总表。标签从 solver-canon 固定词表选择，禁止临场换名（聊天界面会把这一行收成可点击的知识点胶囊）
- 遇到固定词表没有、且确认具备独立定义和解题动作的新考点：先按 `references/knowledge-point-extension.md` 登记，再输出 `### 本题考察知识点：...（新补录）`；后续沿用同一标签
- **双轨解析交付（高分进阶要求）**：每道题需兼顾**【进阶高手秒解 / 直觉锚定法】**（就近对冲、短程降维、极简心算，如大月尾三日直锁定次月一日）与**【考场稳健通解】**（机械化保底步骤）。
- **防粗心物理锚点**：针对思维敏捷但在 ±1、极值设元、区间端点易粗心的痛点，强制给出“草稿纸物理锚点（只写一个关键算式/状态点）”操作建议。
- 日练复盘按对错分流：答对省略空夸奖诊断、标准解析缩短、重点写更快路径；答错写出错因并拆干扰项。下次动作必须 `触发：… → 优先：…`
- 非带图题目必须带完整原题（题干+所有选项）
- 四个选项用 `> **A.**` 各占一行；题干里的 A、B、C 地点或序号不准拆行
- 公式用 `$a^{2}-b^{2}=(a+b)(a-b)$`，与知识点页 Markdown 一致；禁止选项四列表格
- 排版干净清晰，不多余

## 翻译推理记忆口诀（用户验证通过）
详见 `references/translation-reasoning-cheatsheet.md`。核心锚点：
- **「才」是箭头尾巴**：B→A
- **「否则」是反着推**：¬前→后
- **逆否是必做动作**：翻译完立刻写逆否（¬B→¬A）
- **考场四步法**：①写翻译→②写逆否→③排除"肯后"和"否前"→④剩下的就是答案

## AI练题出题与复盘全链路规范
1. 出题阶段：先加载 `quiz-pipeline/references/reference-style-principles.md` 与自动生成的 `reference-style-profile.md`，并通过 `/home/ubuntu/ExamSystem/scripts/reference_style.py context --role generate` 取得同考点真题参考包；独立质量审查另取 `--role evaluate` 留出包。必须使用 AI 练题标准导入格式落库到 /home/ubuntu/ExamSystem/batches/ 下，manifest 写入 `GONGKAO-STYLE` marker 和覆盖全批题的两类 context 溯源。批次 ID 与显示名称统一采用 YYYYMMDD_模块名_编号。题目必须通过后台静默双重校验后导入 DB。
2. 渲染规范：出题题干禁止 LaTeX，用纯文本 Unicode（如 ->、→、!、且、或）。知识点卡与复盘讲解用 Markdown，公式写成 `$...$`，与 ExamSystem 知识点页一致。只使用“解题技巧”“实战技巧”等考场用语，禁止“哈利波特”“黑暗王子”“混血王子”“黑魔法”等包装。
3. 复盘阶段：排版和篇幅一律执行 `references/practice-review-spec.md`。当用户要求结合草稿复盘时，调取 `exam.db` 的 `practice_sessions`、`practice_answers` 与 `practice_drafts`（对应 `/data/draft-images/`），把正确性、单题用时、建议用时和草稿轨迹联动判断。录屏/真题复盘打开用户点名的报告 Markdown，同时用 PDF 判分、录屏行为记录和各题草稿；`#### 草稿诊断` 要落到本题实际行为（停留、跳过、回头、改选项、草稿），不要另开「行为分析」。答对且草稿空或无信息则整段省略草稿诊断，禁止「没问题，继续保持」「确认通过」。对错和分数只认报告开头的 PDF 判分表，禁止用录屏勾选重算，禁止开篇写短处清单、致命失分点或知识点总表。口吻必须逐题 `原题` → `作答结果`（含建议用时对照）→ `#### 草稿诊断`（可省略）→ `#### 标准解析` → `#### 考场解法` → `#### 下次动作`（`触发：… → 优先：…`）→ `#### AI 深度点拨` → `#### 智能统计`。AI 练题和录屏复盘在最后一题之后都必须写 `### 本场结语`（做得好的 / 做得不好的 / 以后怎么改），只针对这一场。知识点不要开篇罗列，只在后台写入画像。错题/空题必须复盘并写出错因。正确但用时偏长、改选项、草稿乱、方法绕或有更快考场解法的，必须给压缩步骤。无草稿只做总时长对比，禁止编造逐步秒数。每一道实际展开的复盘必须先用独立引用块完整展示原题题干与全部选项，让用户能对照思考；禁止只报题号、答案和诊断。 选项必须按 `> **A.**` / `> **B.**` / `> **C.**` / `> **D.**` 各占一行；题干中的 A、B、C 地点或序号必须留在原句，禁止拆成单独一行。禁止省略、横向挤成一行或使用宽表格。AI练题复盘严格只读，不得重复写入画像或登记知识点。录屏/真题复盘相反：视频分析不写画像，讲解时必须按题 `record(..., exam --exam-id --item)` 写一次，命令返回 already recorded 则停。
   - **草稿诊断三维度**：
     ① **符号化程度**：是否能将文字题干抽象为标准逻辑箭头/符号（如 `轨 -> 拆且债`），避免感性语言推理；
     ② **定理落地**：对德摩根定律（`!(A且B) => !A或!B`）、否定肯定式（`(!A或!B) 且 A => !B`）是否有明确划线/化简；
     ③ **坚定度**：结合涂改情况、用时与正确率联动评估（无涂改+符号化化简+高正确率 = 考场降维打击；反复擦改+字面凑答案 = 手感未完全唤醒）。
